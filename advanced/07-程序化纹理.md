# 07 · 程序化纹理

## 概念

程序化纹理 = **用数学函数生成图案**，而不是从图片采样。

优势：

- **零素材**：不需要 UV 展开，不需要贴图文件
- **无限分辨率**：放大不糊
- **参数化**：调一个数字，纹理就变

代价：复杂的真实纹理（如人脸）仍然需要贴图。但**建筑、自然材质**这类规律性强的，程序化完全够用。

## 四大数学纹理节点

| 节点 | 生成什么 | 典型用途 |
|------|---------|---------|
| Noise | 连续的随机起伏 | 斑驳、风化、云雾 |
| Voronoi | 蜂窝状分区 | 砖块、鹅卵石、细胞 |
| Wave | 平滑的波纹/条纹 | 木纹、水波、布纹 |
| Musgrave | 多层分形噪声 | 复杂岩石、山体 |

## Noise 噪声：最重要的一个

Noise 有三个关键参数：

| 参数 | 含义 | 效果 |
|------|------|------|
| Scale | 图案密度 | 大 = 细节多；小 = 大块 |
| Detail | 细节层级 | 越大越"毛"，6~10 比较自然 |
| Roughness | 变化剧烈程度 | 0.5 平滑，0.8 狂躁 |

**输出的 Fac（0~1）** 常接到 ColorRamp，把连续的数值变成颜色分区。

```python
def add_noise(nt, scale=5.0, detail=6.0, rough=0.55, dims="3D", loc=(-550,0)):
    n = nt.nodes.new("ShaderNodeTexNoise")
    n.location = loc
    n.noise_dimensions = dims
    n.inputs["Scale"].default_value = scale
    n.inputs["Detail"].default_value = detail
    n.inputs["Roughness"].default_value = rough
    return n
```

> 💡 **dimensions 参数**：3D 是默认；4D 多一个 W 输入，可以做动画（后面第 11 章的水面流动就用它）；1D/2D 适合贴图。

## Voronoi：砖块与鹅卵石

Voronoi 把空间分成一个个不规则区域，用**到最近特征点的距离**作为输出。

```python
def add_voronoi(nt, scale=6.0, feature="F1", loc=(-550,0)):
    v = nt.nodes.new("ShaderNodeTexVoronoi")
    v.location = loc
    v.feature = feature
    v.inputs["Scale"].default_value = scale
    return v
```

**特性**：
- `feature = "F1"`：到最近点的距离（最常用）
- `feature = "F2 - F1"`：到最近与次近点的距离差 → **清晰的边界线**（砖缝）
- `feature = "SMOOTH_F1"`：平滑版本

## Wave：条纹与木纹

```python
def add_wave(nt, scale=4.0, distortion=2.0, detail=2.0, loc=(-550,0)):
    w = nt.nodes.new("ShaderNodeTexWave")
    w.location = loc
    w.wave_type = "BANDS"
    w.bands_direction = "X"
    w.wave_profile = "SIN"
    w.inputs["Scale"].default_value = scale
    w.inputs["Distortion"].default_value = distortion
    w.inputs["Detail"].default_value = detail
    return w
```

**关键技巧**：把 `Distortion` 拉高（2~8），条纹会变成不规则的自然纹路。配合 Noise 效果更好。

## 实战一：青砖墙（Voronoi + 苔痕）

```python
def mat_brick():
    """青砖墙：Voronoi 砖缝 + 噪声苔痕 + 凹凸。"""
    m, nt, out = new_mat("M_Brick")
    b = add_bsdf(nt, out, rough=0.78)

    tc = add_texcoord(nt)

    # ① 砖块分区
    vor = nt.nodes.new("ShaderNodeTexVoronoi")
    vor.location = (-560, 0)
    vor.feature = "F1"
    vor.distance = "EUCLIDEAN"
    vor.inputs["Scale"].default_value = 6.0
    nt.links.new(tc.outputs["Object"], vor.inputs["Vector"])

    # ② 砖缝 → 砖面
    ramp = add_ramp(nt, [
        (0.02, (0.05, 0.05, 0.05, 1)),   # 缝：深黑
        (0.08, (0.30, 0.28, 0.26, 1)),   # 砖边
        (0.30, (0.36, 0.33, 0.30, 1)),   # 砖面
    ], loc=(-330, 0))
    nt.links.new(vor.outputs["Distance"], ramp.inputs["Fac"])

    # ③ 苔痕：低频噪声决定哪里长苔
    moss = add_noise(nt, scale=4.0, detail=8, rough=0.7, loc=(-560, -260))
    nt.links.new(tc.outputs["Object"], moss.inputs["Vector"])

    mramp = add_ramp(nt, [
        (0.52, (0.0, 0.0, 0.0, 1)),
        (0.66, (0.5, 0.5, 0.5, 1)),
    ], loc=(-330, -260))
    nt.links.new(moss.outputs["Fac"], mramp.inputs["Fac"])

    # ④ 砖色 × 苔痕覆盖
    mixn = add_math(nt, "MULTIPLY", loc=(-100, -260))
    nt.links.new(ramp.outputs["Color"], mixn.inputs[0])
    nt.links.new(mramp.outputs["Color"], mixn.inputs[1])
    nt.links.new(mixn.outputs[0], b.inputs["Base Color"])

    # ⑤ 砖缝凹凸
    add_bump(nt, b, vor.outputs["Distance"], strength=0.5, distance=0.06)
    return m
```

## 实战二：木纹（Wave + Noise 扭曲）

```python
def mat_wood(name="M_Wood", col="#3a281c", rough=0.62):
    m, nt, out = new_mat(name)
    b = add_bsdf(nt, out, base=hex_to_linear(col), rough=rough)

    tc = add_texcoord(nt)

    # 拉伸坐标 → 木纹沿一个方向
    mapping = nt.nodes.new("ShaderNodeMapping")
    mapping.location = (-720, 0)
    mapping.inputs["Scale"].default_value = (1.0, 12.0, 12.0)   # 压扁 → 条纹
    nt.links.new(tc.outputs["Object"], mapping.inputs["Vector"])

    # 条纹 + 扭曲
    wave = add_wave(nt, scale=3.0, distortion=6.0, detail=3.0, loc=(-500, 0))
    nt.links.new(mapping.outputs["Vector"], wave.inputs["Vector"])

    # 颜色分层
    ramp = add_ramp(nt, [
        (0.25, hex_to_linear("#241609")),
        (0.55, hex_to_linear(col)),
        (0.85, hex_to_linear("#5a4028")),
    ], loc=(-260, 0))
    nt.links.new(wave.outputs["Fac"], ramp.inputs["Fac"])
    nt.links.new(ramp.outputs["Color"], b.inputs["Base Color"])

    # 木纹凹凸
    add_bump(nt, b, wave.outputs["Fac"], strength=0.18, distance=0.03)
    return m
```

**关键**：Mapping 节点的 Scale 把 Y/Z 压扁，条纹就沿 X 方向延伸——这是木纹的方向感来源。

## 实战三：水面（Wave + 4D 噪声动画）

江南水巷的水面靠两层叠加：基础波纹 + 流动噪声。

```python
def mat_water():
    m, nt, out = new_mat("M_Water")
    b = add_bsdf(nt, out, base=(0.02, 0.04, 0.06, 1), rough=0.08, metal=0.0)

    tc = add_texcoord(nt)

    # ① 大波纹
    wave = add_wave(nt, scale=1.6, distortion=2.5, detail=2.0, loc=(-560, 100))
    wave.wave_type = "RINGS"
    nt.links.new(tc.outputs["Object"], wave.inputs["Vector"])

    # ② 细密流动（4D，W 随时间变化）
    flow = add_noise(nt, scale=8.0, detail=6, rough=0.6, dims="4D", loc=(-560, -160))
    nt.links.new(tc.outputs["Object"], flow.inputs["Vector"])

    # ③ 高度 = 波纹 + 流动
    add = add_math(nt, "ADD", loc=(-330, 0))
    nt.links.new(wave.outputs["Fac"], add.inputs[0])
    nt.links.new(flow.outputs["Fac"], add.inputs[1])

    # ④ 法线
    add_bump(nt, b, add.outputs[0], strength=0.35, distance=0.12)

    # ⑤ W 随帧变化 → 流动动画
    sock = flow.inputs["W"]
    sock.default_value = 0.0
    sock.keyframe_insert("default_value", frame=1)
    sock.default_value = 3.2
    sock.keyframe_insert("default_value", frame=240)
    return m
```

**给节点的输入打关键帧**是 Blender 的通用技巧——任何 socket 都可以 `keyframe_insert("default_value", frame=N)`。

## 实战四：水面倒影光柱（进阶）

水面上那一道道发光的倒影，其实不是真实反射（光追倒影不可靠），而是**画上去的**。

思路：每个发光体正下方铺一条梯形光带，用 UV 渐变 × 横向软边 × 流动噪声控制。

```python
def make_streak_mesh():
    """反射光柱单元：局部 y 从 0（光源正下方）延伸到 -1（远处）。"""
    me = bpy.data.meshes.new("StreakMesh")
    me.from_pydata(
        [(-0.5, 0, 0), (0.5, 0, 0), (0.20, -1, 0), (-0.20, -1, 0)],
        [], [(0, 1, 2, 3)])
    me.update()

    # 手工写 UV：v 从 1（近）到 0（远）
    uvl = me.uv_layers.new(name="UVMap")
    for i, uv in enumerate([(0.0, 1.0), (1.0, 1.0), (1.0, 0.0), (0.0, 0.0)]):
        uvl.data[i].uv = uv
    return me


def mat_streak():
    """倒影光柱材质：UV 渐变 × 横向软边 × 流动噪声 → 半透明发光带。"""
    m, nt, out = new_mat("M_Streak")
    b = add_bsdf(nt, out, base=(0,0,0,1), rough=1.0,
                 emit=hex_to_linear("#ff8034"), emit_str=1.35)

    tc = add_texcoord(nt)
    sep = nt.nodes.new("ShaderNodeSeparateXYZ"); sep.location = (-520, 0)
    nt.links.new(tc.outputs["UV"], sep.inputs[0])

    # 纵向渐变：近亮远暗
    grad = add_ramp(nt, [
        (0.00, (0.00, 0.00, 0.00, 1)),
        (0.45, (0.22, 0.22, 0.22, 1)),
        (0.80, (0.55, 0.55, 0.55, 1)),
        (1.00, (1.00, 1.00, 1.00, 1)),
    ], loc=(-330, 60))
    nt.links.new(sep.outputs["Y"], grad.inputs["Fac"])

    # 横向软边
    side = add_ramp(nt, [
        (0.00, (0.0, 0.0, 0.0, 1)),
        (0.32, (0.75, 0.75, 0.75, 1)),
        (0.68, (0.75, 0.75, 0.75, 1)),
        (1.00, (0.0, 0.0, 0.0, 1)),
    ], loc=(-330, -140))
    nt.links.new(sep.outputs["X"], side.inputs["Fac"])

    # 流动噪声
    n = add_noise(nt, scale=34.0, detail=8, rough=0.62, dims="4D", loc=(-330, -280))
    nr = add_ramp(nt, [(0.30, (0,0,0,1)), (0.62, (1,1,1,1))], loc=(-140, -280))
    nt.links.new(n.outputs["Fac"], nr.inputs["Fac"])

    # 三层相乘 → Alpha
    mul1 = add_math(nt, "MULTIPLY", loc=(60, 40))
    nt.links.new(grad.outputs["Color"], mul1.inputs[0])
    nt.links.new(side.outputs["Color"], mul1.inputs[1])
    mul2 = add_math(nt, "MULTIPLY", loc=(200, -60))
    nt.links.new(mul1.outputs[0], mul2.inputs[0])
    nt.links.new(nr.outputs["Color"], mul2.inputs[1])
    nt.links.new(mul2.outputs[0], b.inputs["Alpha"])

    # 半透明混合
    try:
        m.surface_render_method = "BLENDED"
    except Exception:
        try:
            m.blend_method = "BLEND"
        except Exception:
            pass
    m.use_backface_culling = False
    return m
```

**这是"用假的东西替代真的物理"的经典案例**：不追求物理正确，只追求视觉效果。倒影光柱数量可以到几百条，渲染却几乎不增加负担。

## 纹理坐标的选择

`Texture Coordinate` 节点有几个输出，选哪个很重要：

| 输出 | 含义 | 适用 |
|------|------|------|
| `Generated` | 物体包围盒归一化坐标 | 贴图类，随物体缩放 |
| `Object` | 物体本地坐标 | **程序化纹理首选**，尺寸真实 |
| `UV` | UV 展开坐标 | 需要展开的贴图 |
| `Generated` + `Object` | — | — |

> 💡 **程序化纹理用 `Object`**。它的坐标是真实米制，所以 Scale=1 意味着 1 米一个周期，不同大小的物体纹理密度一致。

## 组合技巧清单

| 想要的效果 | 做法 |
|-----------|------|
| 分层斑驳 | 两层 Noise → ColorRamp → 相乘 |
| 砖缝 | Voronoi F1 → ColorRamp（窄缝用小 position） |
| 木纹 | Mapping 压扁 + Wave + Distortion |
| 苔痕 | 低频 Noise → ColorRamp（阈值高，只在局部） |
| 水波 | Wave(RINGS) + 4D Noise → Bump |
| 金属划痕 | Wave 高频 + Mapping 强压扁 + 低 Roughness |
| 灯箱发光 | Emission + Noise 调制强度 |

## 本章要点回顾

- Noise / Voronoi / Wave 是三大主力纹理节点
- **Noise → ColorRamp** 是最常用的组合，把连续值变成分层颜色
- Mapping 的 Scale 压缩能造方向感（木纹、布纹）
- 程序化纹理用 `Object` 坐标，尺寸真实
- 4D Noise 的 W 输入打关键帧 = 流动动画
- **必要时用"假效果"替代物理**：倒影光柱就是例子
