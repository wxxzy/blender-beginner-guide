# 10 · 关键帧与运镜

## 概念

关键帧不是"记录某一刻的样子"，而是**描述一条曲线**。Blender 会在关键帧之间插值出连续的变化。

```
关键帧：位置 = 0 → 位置 = 10
中间帧：位置由插值方式决定
```

**插值方式决定了运动的"性格"**——这是运镜设计的核心。

## 打关键帧

```python
obj = bpy.data.objects.get("Camera")

obj.location = (0, -10, 5)
obj.keyframe_insert("location", frame=1)      # 第 1 帧记录当前位置

obj.location = (0, 0, 3)
obj.keyframe_insert("location", frame=100)    # 第 100 帧记录新位置
```

`keyframe_insert` 的第一个参数是**数据路径**（属性名），可以打关键帧的属性很多：

```python
obj.keyframe_insert("location", frame=1)
obj.keyframe_insert("rotation_euler", frame=1)
obj.keyframe_insert("scale", frame=1)
obj.keyframe_insert("hide_render", frame=1)     # 布尔属性也能打
obj.keyframe_insert('["my_prop"]', frame=1)     # 自定义属性
```

**数据路径也能用在非物体上**——材质节点的输入、灯光的强度都能打关键帧：

```python
noise.inputs["W"].keyframe_insert("default_value", frame=1)
```

## 插值方式

### 获取 F-Curve（5.2 的关键变化）

```python
def fcurves_of(idblock):
    """Blender 5.x slotted-action 兼容：取出某个 ID 的全部 fcurve。"""
    ad = getattr(idblock, "animation_data", None)
    if not ad or not ad.action:
        return []
    act = ad.action
    # 旧版路径（兼容）
    try:
        if hasattr(act, "fcurves") and len(act.fcurves):
            return list(act.fcurves)
    except Exception:
        pass
    # 5.x 新路径
    out = []
    for layer in getattr(act, "layers", []):
        for strip in getattr(layer, "strips", []):
            for cb in getattr(strip, "channelbags", []):
                out.extend(getattr(cb, "fcurves", []))
    return out
```

> ⚠️ **Blender 5.x 移除了 `Action.fcurves`**，必须走 `action.layers[].strips[].channelbags[].fcurves`。
>
> 上面这个函数**同时兼容新旧版本**，是本教程推荐的通用写法。

### 常用的插值类型

| 类型 | 效果 | 适用 |
|------|------|------|
| `BEZIER` | 平滑起停（默认） | 大部分镜头运动 |
| `LINEAR` | 匀速 | 匀速运动、机械感 |
| `CONSTANT` | 阶跃 | 切换、闪断 |

### 控制柄类型

| 类型 | 效果 |
|------|------|
| `AUTO_CLAMPED` | 自动平滑，且**不超调**（推荐） |
| `AUTO` | 自动平滑，可能超调 |
| `VECTOR` | 直线连接 |

```python
for fc in fcurves_of(cam):
    for kp in fc.keyframe_points:
        kp.interpolation = "BEZIER"
        kp.handle_left_type = "AUTO_CLAMPED"
        kp.handle_right_type = "AUTO_CLAMPED"
```

**`AUTO_CLAMPED` 是运镜的默认选择**：它保证曲线不会在关键帧之间冲出预期范围。

## 实战：六段式推进运镜

江南水巷的镜头从高空俯瞰一路推进到桥头。这需要**位置和朝向各打 6 组关键帧**。

```python
def build_camera(coll, sc):
    cd = bpy.data.cameras.new("CAM_Main")
    cd.lens = 30
    cd.sensor_width = 36
    cd.clip_start = 0.1
    cd.clip_end = 400
    cam = bpy.data.objects.new("CAM_Main", cd)
    coll.objects.link(cam)
    sc.camera = cam

    # (帧号, 位置, 注视点)
    keys = [
        (1,   (1.35, -40.0, 7.10), (0.7, -10.0, 2.6)),    # 高空俯瞰
        (52,  (1.10, -30.0, 5.20), (0.8, -2.0, 3.0)),
        (104, (0.55, -20.0, 3.55), (0.9, 7.0, 3.4)),
        (156, (-0.20, -13.0, 2.60), (1.0, 11.0, 3.8)),
        (204, (-1.15, -7.6, 2.30), (1.30, 15.5, 4.55)),   # 逼近拱桥
        (240, (-1.00, -3.4, 2.25), (1.30, 17.0, 4.75)),   # 桥头定格
    ]

    for f, loc, tgt in keys:
        cam.location = loc
        # 朝向由"位置 → 注视点"向量决定
        cam.rotation_euler = (Vector(tgt) - Vector(loc)).to_track_quat("-Z", "Y").to_euler()
        cam.keyframe_insert("location", frame=f)
        cam.keyframe_insert("rotation_euler", frame=f)

    # 统一插值
    for fc in fcurves_of(cam):
        for kp in fc.keyframe_points:
            kp.interpolation = "BEZIER"
            kp.handle_left_type = "AUTO_CLAMPED"
            kp.handle_right_type = "AUTO_CLAMPED"

    return cam
```

### 关键设计：朝向也是算出来的

不要手动转相机角度。**用"看向某个点"反推旋转**：

```python
cam.rotation_euler = (Vector(target) - Vector(cam.location)).to_track_quat("-Z", "Y").to_euler()
```

这样每个关键帧只需给出"我在哪"和"我看哪"，画面自然连贯。

## 加一点手持抖动

真实摄影机不可能绝对平稳。给位置曲线加噪声修改器：

```python
for fc in fcurves_of(cam):
    for kp in fc.keyframe_points:
        kp.interpolation = "BEZIER"
        kp.handle_left_type = "AUTO_CLAMPED"
        kp.handle_right_type = "AUTO_CLAMPED"

    # 只给水平(X)和高度(Z)加噪声，Y 方向保持干净
    if fc.array_index in (0, 2) and "location" in fc.data_path:
        mod = fc.modifiers.new("NOISE")
        mod.strength = 0.03      # 抖动幅度（米）
        mod.scale = 50           # 抖动频率
        mod.phase = 12 if fc.array_index == 2 else 31   # 错开相位
```

**这是"假的东西替代真的物理"的又一例**：不用真去模拟手持抖动，加个噪声修改器就行。

## 图编辑器（Graph Editor）

关键帧的曲线形状在**图编辑器**里看得最清楚：

```python
bpy.ops.graph.interpolation_type(type="BEZIER")
```

界面操作：选中物体 → 切换到"动画 / 图形编辑器"工作区 → 看到所有 F-Curve。

**读曲线的方法**：
- 曲线**陡**的地方 = 运动快
- 曲线**平**的地方 = 运动慢
- 要让镜头匀速，曲线要接近**直线**

## 物体动画：摇橹

乌篷船的摇橹是简单的周期运动：

```python
def animate_rowing(obj, frames=(1, 60, 120, 180, 240), angle=25.0):
    """摇橹：绕一个轴往复摆动。"""
    pivot = Vector((0, 0, 0))
    for f, sign in zip(frames, (1, -1, 1, -1, 1)):
        obj.rotation_euler = (0, 0, 0)
        obj.location = pivot
        obj.rotation_euler.x = math.radians(angle) * sign
        obj.keyframe_insert("rotation_euler", frame=f)

    for fc in fcurves_of(obj):
        for kp in fc.keyframe_points:
            kp.interpolation = "BEZIER"
            kp.handle_left_type = "AUTO_CLAMPED"
            kp.handle_right_type = "AUTO_CLAMPED"
```

配合 **Cycles 修改器**可以无限循环：

```python
for fc in fcurves_of(obj):
    if "rotation" in fc.data_path:
        fc.modifiers.new("CYCLES")
```

## 时间线与播放

```python
sc.frame_start = 1
sc.frame_end = 240
sc.render.fps = 24        # 24fps → 240 帧 = 10 秒
```

**帧率决定时长**。24fps 是电影标准，240 帧正好 10 秒。

## 关键帧的三个技巧

### ① 用"烘焙"代替逐帧打关键帧

```python
# 逐帧设置 + 打关键帧（用于复杂程序化动画）
for f in range(1, 241):
    t = (f - 1) / 239.0
    obj.location = (math.sin(t * math.pi * 4) * 0.3, t * 10, 2.0)
    obj.keyframe_insert("location", frame=f)
```

这样能做出任意复杂的运动，代价是关键帧数量暴增。

### ② 修改器可以叠加

一个 F-Curve 上可以挂多个修改器（噪声、生成器、限制、循环），它们**按顺序叠加**。

### ③ 关键帧可以复制

```python
fc.keyframe_points.insert(frame, options={'FAST'})
```

## 本章要点回顾

- 关键帧描述的是**曲线**，插值方式决定运动性格
- **`AUTO_CLAMPED`** 是运镜的默认选择（平滑且不超调）
- **5.x 的 F-Curve 路径变了**，用 `fcurves_of()` 兼容新旧
- 相机朝向用 `to_track_quat` 从"看向哪里"反推
- 噪声修改器 = 假的手持抖动
- Cycles 修改器 = 无限循环动画
- 24fps × 240 帧 = 10 秒
