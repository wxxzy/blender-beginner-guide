# 04 · 曲线与文字对象

## 概念

曲线（Curve）是 Blender 的第四种几何类型——介于网格和点之间。它有三大优势：

1. **可参数化**：改控制点数量、位置，整条曲线实时更新
2. **可挤出**：一条曲线 + 一个挤出参数 = 一串几何体（栏杆、灯串、字）
3. **可文字化**：中文招牌直接用文字对象，不用找模型

## 三种曲线类型

| 类型 | 控制点 | 用途 |
|------|--------|------|
| Poly | 顶点 | 折线，尖锐转折 |
| Bezier | 控制柄 | 平滑曲线，最常用 |
| NURBS | 控制点 + 权重 | 精确圆弧 |

## 创建与编辑

```python
import bpy, math

def make_poly_curve(name, points, cyclic=False):
    cu = bpy.data.curves.new(name, "CURVE")
    cu.dimensions = "3D"
    cu.resolution_u = 12          # 贝塞尔段数，越高越平滑

    sp = cu.splines.new("BEZIER")
    sp.bezier_points.add(len(points) - 1)
    for bp, co in zip(sp.bezier_points, points):
        bp.co = co
        bp.handle_left_type = "AUTO"
        bp.handle_right_type = "AUTO"
    sp.use_cyclic_u = cyclic

    obj = bpy.data.objects.new(name, cu)
    bpy.context.scene.collection.objects.link(obj)
    return obj

def make_poly_curve2(name, points, cyclic=False):
    """折线版本（POLY）——控制点就是顶点，不做平滑。"""
    cu = bpy.data.curves.new(name, "CURVE")
    cu.dimensions = "3D"
    sp = cu.splines.new("POLY")
    sp.points.add(len(points) - 1)
    for p, co in zip(sp.points, points):
        p.co = (co[0], co[1], co[2], 1.0)
    sp.use_cyclic_u = cyclic

    obj = bpy.data.objects.new(name, cu)
    bpy.context.scene.collection.objects.link(obj)
    return obj
```

> 💡 **贝塞尔 vs 折线**：贝塞尔控制柄自动计算平滑度，但**直线段会鼓包**。要精确的直线（比如栏杆横杆），用 POLY 类型。

## 挤出曲线成几何

这是曲线的杀手级应用。给曲线加一个挤出修改器：

```python
def curve_to_tube(name, points, radius=0.03, cyclic=False, segments=8):
    """生成一根管状结构（栏杆、灯绳、灯笼骨架）。"""
    obj = make_poly_curve2(name, points, cyclic)
    obj.data.bevel_depth = radius        # 圆的截面半径
    obj.data.bevel_resolution = 4        # 截面细分数
    obj.data.fill_mode = "FULL"          # 封口
    obj.data.use_fill_caps = True
    return obj
```

**关键属性**（都在 `curve.data` 上）：

| 属性 | 作用 |
|------|------|
| `bevel_depth` | 挤出半径 |
| `bevel_resolution` | 截面圆度（0=方形，4+ = 圆） |
| `extrude` | 沿曲线法线方向拉伸（不加 bevel 就是"带状面"） |
| `fill_mode` | FULL / FRONT / BACK / HALF |
| `use_fill_caps` | 是否封口 |
| `resolution_u` | 贝塞尔细分精度 |

## 实战：跨河灯串

江南水巷的灯串——一条悬垂的绳子，串着一串灯笼。

```python
def make_lantern_string(name, y, z_top, sag=0.55, n=7, span=10.0):
    """生成一条悬垂灯串：主绳 + 每盏灯的位置。"""
    # ① 悬垂曲线：两端固定，中间下垂
    pts = []
    for i in range(13):
        t = i / 12
        x = -span / 2 + span * t
        # 抛物线下垂
        drop = sag * 4 * t * (1 - t)
        pts.append((x, y, z_top - drop))

    rope = curve_to_tube(name + "_Rope", pts, radius=0.012)

    # ② 每盏灯的位置（沿曲线采样）
    lamp_positions = []
    for i in range(n):
        t = (i + 0.5) / n
        x = -span / 2 + span * t
        drop = sag * 4 * t * (1 - t)
        lamp_positions.append((x, y, z_top - drop - 0.10))

    return rope, lamp_positions
```

**验证**：场景里出现一条下垂的细绳，返回 7 个灯笼挂点。

## 实战：中文发光招牌

文字对象 + 曲线挤出 + 自发光材质：

```python
def make_sign(name, body, font_path, size=0.42, loc=(0, 0, 0),
              normal=(0, -1, 0), color="#ff8a3c", strength=3.0):
    """生成一块中文发光招牌（挑出式，垂直于立面）。"""
    cu = bpy.data.curves.new(name, "FONT")
    cu.body = body
    cu.font = bpy.data.fonts.load(font_path)
    cu.size = size
    cu.extrude = 0.02               # 文字有厚度
    cu.align_x = "CENTER"
    cu.align_y = "CENTER"

    obj = bpy.data.objects.new(name, cu)
    bpy.context.scene.collection.objects.link(obj)
    obj.location = loc

    # 面向法线方向
    from mathutils import Vector
    obj.rotation_euler = Vector(normal).to_track_quat("Z", "Y").to_euler()

    # 发光材质
    mat = bpy.data.materials.new(name + "_M")
    mat.use_nodes = True
    b = next(n for n in mat.node_tree.nodes if n.type == "BSDF_PRINCIPLED")
    b.inputs["Emission Color"].default_value = hex_to_linear(color)
    b.inputs["Emission Strength"].default_value = strength
    b.inputs["Base Color"].default_value = (0.01, 0.01, 0.01, 1)
    obj.data.materials.append(mat)
    return obj
```

**颜色要转线性空间**——这是新手常犯的错，直接给 sRGB 值会偏色：

```python
def _s2l(c):
    return c / 12.92 if c <= 0.04045 else ((c + 0.055) / 1.055) ** 2.4

def hex_to_linear(h, a=1.0):
    h = h.lstrip("#")
    r, g, b = (int(h[i:i+2], 16) / 255.0 for i in (0, 2, 4))
    return (_s2l(r), _s2l(g), _s2l(b), a)
```

## 实战：栏杆（重复结构）

栏杆 = 一条横杆曲线 + 竖杆阵列。曲线 + 阵列修改器的组合：

```python
def make_railing(name, length=6.0, height=0.9, posts=12):
    # 横杆（略带上翘的中式感）
    pts = [(-length/2, 0, height), (length/2, 0, height)]
    rail = curve_to_tube(name + "_Rail", pts, radius=0.035)
    rail.data.bevel_resolution = 6

    # 竖杆
    bpy.ops.mesh.primitive_cube_add(size=1.0)
    post = bpy.context.active_object
    post.dimensions = (0.05, 0.05, height)
    post.location = (-length/2, 0, height/2)
    post.name = name + "_Post"

    arr = post.modifiers.new("Array", "ARRAY")
    arr.count = posts
    arr.use_relative_offset = False
    arr.use_constant_offset = True
    arr.constant_offset_displace = (length / (posts - 1), 0, 0)

    return rail, post
```

```

constraint = obj.constraints.new("FOLLOW_PATH")

constraint.use_curve_follow = True
```

### 转为网格（需要进一步编辑时）

```python
bpy.ops.object.convert(target="MESH")
```

## 本章要点回顾

- 曲线是参数化的几何，**改控制点比改网格容易得多**
- POLY 适合直线段，BEZIER 适合平滑曲线
- `bevel_depth` + `bevel_resolution` 把曲线变成管状体
- 文字对象用系统字体，中文招牌直接 `bpy.data.fonts.load()`
- **颜色要转线性空间**，否则会偏色
- 曲线 + 阵列修改器 = 重复结构的标准做法
