# 11 · 约束与驱动器

## 概念

关键帧是"我告诉你每一刻在哪"。约束和驱动器是"**我描述一条规则，Blender 自己算**"。

| | 关键帧 | 约束 / 驱动器 |
|---|---|---|
| 描述方式 | 逐个时刻的值 | 一条规则 |
| 适合 | 已定好的运动 | 需要自动响应的情况 |
| 例子 | 相机从 A 飞到 B | 相机始终看向目标 |

## 约束（Constraint）

约束是**物体之间的关系**。加在 B 上，让 B 跟随 A。

### 常用约束

| 约束 | 作用 |
|------|------|
| `COPY_LOCATION` | 复制位置 |
| `TRACK_TO` | 始终朝向某个目标 |
| `FOLLOW_PATH` | 沿曲线运动 |
| `PARENT` | 父子关系（带偏移选项） |
| `LIMIT_LOCATION` | 限制位置范围 |
| `DAMPED_TRACK` | 平滑朝向 |
| `LOCKED_TRACK` | 锁定某个轴朝向 |

### 实战：相机始终看向目标

```python
def add_track_to(cam, target):
    c = cam.constraints.new("TRACK_TO")
    c.target = target
    c.track_axis = "TRACK_NEGATIVE_Z"    # 相机朝 -Z
    c.up_axis = "UP_Y"
    return c
```

**比每帧打关键帧更省事**：移动目标物体，相机自动跟随。

### 实战：物体沿曲线运动

```python
def follow_curve(obj, curve, offset=0.0):
    c = obj.constraints.new("FOLLOW_PATH")
    c.target = curve
    c.use_curve_follow = True      # 物体朝向跟随曲线切线
    c.forward_axis = "FORWARD_Y"
    c.up_axis = "UP_Z"
    c.offset_factor = offset       # 0~1，初始位置
    return c
```

**曲线需要设好路径动画**才能用：

```python
curve_obj.data.path_duration = 240     # 路径动画长度
curve_obj.data.use_path = True
```

### 约束的混合模式

一个物体可以有多条约束，靠**混合模式**决定它们如何叠加：

- `REPLACE`（替换）：只用这条约束
- `ADD`（叠加）：和之前的约束结果相加
- `BEFORE` / `AFTER`：在之前/之后应用

## 驱动器（Driver）

驱动器是**用公式计算属性值**。可以驱动任何可动画化的属性。

### 基本结构

```
驱动器 = 变量（从某个对象取数） + 表达式
```

```python
def add_driver(owner, path, index=-1, expression="v", var_specs=None):
    """给 owner 的某个属性加驱动器。

    owner      —— 目标对象
    path       —— 数据路径，如 "location" / "rotation_euler" / '["custom"]'
    index      —— 分量索引，-1 表示整个属性
    expression —— 表达式，如 "v * 2"
    var_specs  —— 变量定义列表 [(变量名, 目标对象, 数据路径), ...]
    """
    if index >= 0:
        fcurve = owner.driver_add(path, index)
    else:
        fcurve = owner.driver_add(path)
    drv = fcurve.driver
    drv.type = "SCRIPTED"

    for name, id_obj, data_path in (var_specs or []):
        var = drv.variables.new()
        var.name = name
        var.type = "SINGLE_PROP"
        var.targets[0].id = id_obj
        var.targets[0].data_path = data_path

    drv.expression = expression
    return drv
```

### 实战：空物体驱动阵列数量

```python
ctrl = bpy.data.objects.new("CTRL_Count", None)
ctrl.empty_display_size = 0.5
bpy.context.scene.collection.objects.link(ctrl)
ctrl["count"] = 20

add_driver(
    ctrl, '["count"]',
    expression="max(1, int(c))",
    var_specs=[("c", ctrl, '["count"]')],
)
```

现在拖动空物体的自定义属性 `count`，被驱动的属性实时变化。

### 实战：用时间驱动属性

```python
# 水面的波纹强度随时间变化
add_driver(
    mat.node_tree, 'nodes["Noise"].inputs["W"]',
    expression="frame / 60.0",
)
```

**`frame` 是驱动器的内置变量**，可以直接在表达式里用，不需要手动声明。

常用内置变量：

| 变量 | 含义 |
|------|------|
| `frame` | 当前帧号 |
| `pi` | π |

### 表达式里的数学函数

驱动器的表达式支持完整的 Python 数学函数：

```python
expression="sin(frame/30.0) * 0.5 + 0.5"
expression="max(0, min(1, v))"
expression="abs(v) ** 2"
```

> ⚠️ 出于安全考虑，驱动器表达式**默认禁用** `import` 等语句，只能用白名单里的数学函数。

### 实战：让物体跟着曲线参数动

```python
# 灯笼沿灯串曲线摆动，幅度随时间
add_driver(
    lantern, "rotation_euler", index=2,
    expression="sin(frame/15.0) * 0.1",
)
```

## 父子级（Parenting）

约束之外，传统的父子级也很重要。

```python
child.parent = parent
child.matrix_parent_inverse = parent.matrix_world.inverted()
```

**`matrix_parent_inverse` 是关键**。不设它，子物体会在设置父级的瞬间"跳"到父级原点。

更简单安全的做法是**先设父级再设位置**：

```python
child.parent = parent
child.location = (0, 0, 0)     # 相对父级的位置
```

### 父级类型

| 类型 | 特点 |
|------|------|
| Object | 普通父子，子物体继承父级变换 |
| Armature | 骨骼蒙皮 |
| Vertex | 三个顶点三角形父级（做布料飘动用） |

## 三种"跟随"方案怎么选

| 需求 | 方案 |
|------|------|
| 相机看向某个物体 | `TRACK_TO` 约束 |
| 物体沿路径移动 | `FOLLOW_PATH` 约束 |
| 复杂的、逐帧变化的运动 | 关键帧 |
| 数值随其他属性联动 | 驱动器 |
| 纯粹的层级关系 | 父子级 |

## 组织脚本：工具函数库

随着项目变大，把工具函数抽出来：

```python
# ---- utils.py ----
import bpy, math
from mathutils import Vector

def fcurves_of(idblock):
    """Blender 5.x slotted-action 兼容。"""
    ad = getattr(idblock, "animation_data", None)
    if not ad or not ad.action:
        return []
    act = ad.action
    try:
        if hasattr(act, "fcurves") and len(act.fcurves):
            return list(act.fcurves)
    except Exception:
        pass
    out = []
    for layer in getattr(act, "layers", []):
        for strip in getattr(layer, "strips", []):
            for cb in getattr(strip, "channelbags", []):
                out.extend(getattr(cb, "fcurves", []))
    return out


def smooth_all(idblock, interp="BEZIER", handle="AUTO_CLAMPED"):
    """把所有 F-Curve 的插值统一设置。"""
    for fc in fcurves_of(idblock):
        for kp in fc.keyframe_points:
            kp.interpolation = interp
            kp.handle_left_type = handle
            kp.handle_right_type = handle


def add_driver(owner, path, index=-1, expression="v", var_specs=None):
    """给属性加驱动器（详见本章）。"""
    if index >= 0:
        fcurve = owner.driver_add(path, index)
    else:
        fcurve = owner.driver_add(path)
    drv = fcurve.driver
    drv.type = "SCRIPTED"
    for name, id_obj, data_path in (var_specs or []):
        var = drv.variables.new()
        var.name = name
        var.type = "SINGLE_PROP"
        var.targets[0].id = id_obj
        var.targets[0].data_path = data_path
    drv.expression = expression
    return drv


def new_collection(name, parent=None):
    """新建集合并链接到场景。"""
    coll = bpy.data.collections.new(name)
    (parent or bpy.context.scene.collection).children.link(coll)
    return coll


def link(obj, coll):
    """把物体链接到集合。"""
    for c in list(obj.users_collection):
        c.objects.unlink(obj)
    coll.objects.link(obj)
    return obj
```

## 本章要点回顾

- 约束描述"物体之间的关系"，驱动器描述"一条计算规则"
- `TRACK_TO` 让相机自动看向目标，省掉大量关键帧
- `FOLLOW_PATH` 让物体沿曲线走，配合 `use_path`
- 驱动器需要"变量 + 表达式"两部分
- **`frame` 是驱动器内置变量**，可直接在表达式里用
- 设父级后要处理 `matrix_parent_inverse`，否则会跳位
- 把工具函数抽成 `utils.py`，项目越大越值得
