# 进阶版教程规划

## 定位

| | 初级版（已发布） | 进阶版（本规划） |
|---|---|---|
| 目标 | 会用 Blender | 会用 Blender **造东西** |
| 核心问题 | "这个按钮在哪？" | "怎么让 30 栋房子各自动生成？" |
| 学习方式 | 鼠标点击 + 快捷键 | **写脚本驱动 Blender** |
| 最终产出 | 一个简单模型 | 一个完整场景 / 短片 |
| 建议前置 | 无 | 完成初级版 + 会一点 Python |

**一句话概括进阶版的核心跃迁**：
> 初级版教你"手动做一个模型"；进阶版教你"写一个脚本，自动做一千个"。

---

## 五个能力模块

### 模块一：程序化建模（Procedural Modeling）
**核心问题**：手动建模效率低，改一次要重做。

| 章节 | 内容 | 实战产出 |
|---|---|---|
| 1.1 | Python 控制 Blender 的基本模型：`bpy` 上下文、数据块、集合 | 脚本创建带材质的立方体 |
| 1.2 | bmesh：绕过界面直接操作网格顶点 | 脚本生成一个带圆角的石柱 |
| 1.3 | 修改器系统：倒角/阵列/布尔/细分的正确用法与顺序 | 用修改器做一面砖墙 |
| 1.4 | 程序化曲面：数学函数生成屋顶/布料/山脉 | 参数化生成中式起翘屋面 |
| 1.5 | 曲线与文字：样条曲线 + 挤出 + 字体 | 生成招牌、栏杆、灯笼骨架 |
| 1.6 | 几何节点入门：可视化编程代替代码 | 用几何节点撒一片瓦当 |

### 模块二：程序化材质（Procedural Materials）
**核心问题**：贴图素材有限，质感重复。

| 章节 | 内容 | 实战产出 |
|---|---|---|
| 2.1 | 节点编辑器思维：把材质当"电路图" | 理解并修改一个现成节点组 |
| 2.2 | 程序化纹理：Noise / Voronoi / Wave / Musgrave | 无贴图的白墙风化材质 |
| 2.3 | 色彩管理：Color Ramp / Hue Sat / Mix 的正确接法 | 做青砖、木纹、苔痕三种材质 |
| 2.4 | 法线与凹凸：Bump、Displacement、法线贴图 | 砖墙的凹凸质感 |
| 2.5 | 高级混合：透明、发光、菲涅尔、Layer Weight | 水面/玻璃/金属的物理正确表现 |

### 模块三：灯光与渲染管线（Lighting & Rendering）
**核心问题**：模型做完了，画面难看。

| 章节 | 内容 | 实战产出 |
|---|---|---|
| 3.1 | 光源类型与物理原理：点/面/聚/太阳/区域 | 布一盏像样的主光 |
| 3.2 | 色温与色彩关系：冷暖对比、互补色 | 夜景的蓝橙对撞 |
| 3.3 | EEVEE vs Cycles：如何选、采样与降噪 | 同一场景两种引擎对比 |
| 3.4 | 后期合成：Glare / ColorBalance / 曲线 / 暗角 | 一条完整的后期链路 |
| 3.5 | 性能优化：面数、light bounces、阴影设置 | 让渲染时间减半 |

### 模块四：动画与镜头（Animation & Camera）
**核心问题**：静态画面会腻。

| 章节 | 内容 | 实战产出 |
|---|---|---|
| 4.1 | 关键帧的本质：插值、缓动、图编辑器 | 给相机打关键帧 |
| 4.2 | 运镜设计：推轨摇移的语法与节奏 | 六段式贝塞尔运镜 |
| 4.3 | 约束与父子级：跟随、复制位置、曲线路径 | 摄像机沿路径运动 |
| 4.4 | 驱动器与表达式：用公式控制属性 | 用时间驱动水面波动 |
| 4.5 | 材质动画：给噪声打关键帧做流动感 | 流动的水面倒影 |

### 模块五：工程化与产出（Engineering & Delivery）
**核心问题**：场景大了就乱，出不了片。

| 章节 | 内容 | 实战产出 |
|---|---|---|
| 5.1 | 场景组织：集合、命名、库链接 | 一套可维护的场景结构 |
| 5.2 | 数据复用：链接数据 vs 复制数据 | 100 栋房子只占 1 份数据 |
| 5.3 | 自动化渲染：命令行批量出图 | 一条命令出 32 帧 |
| 5.4 | 输出格式：视频序列、帧序列、色彩空间 | 交付用的帧序列 |
| 5.5 | 完整实战：复刻一个完整场景 | 一个 240 帧短片 |

## 贯穿案例：江南水巷夜景

所有模块用**同一个贯穿案例**串联，避免学完就忘：

```
模块一  →  程序化生成河道、石拱桥、30 栋民居、乌篷船
模块二  →  白墙风化、青砖、木纹、苔痕、水面材质
模块三  →  月光 + 天光 + 70 盏灯笼 + 后期链路
模块四  →  相机从高空俯瞰推进到桥头 + 船摇橹
模块五  →  命令行渲染 240 帧 + 组织成片
```

学完能完整复现 `output/river_town/` 那个场景。

## 章节组织建议

我倾向 **12~14 篇**，每篇对应 1~2 个小节，每篇 15~30 分钟阅读 + 实操：

```
00- 进阶版导读：与初级版的区别、环境准备
01- Python 控制 Blender 基础
02- bmesh 网格编程
03- 修改器系统
04- 程序化曲面生成
05- 曲线与文字对象
06- 几何节点入门
07- 节点编辑器与程序化纹理
08- 色彩管理与高级材质
09- 灯光系统
10- 渲染引擎与后期合成
11- 动画、运镜与约束
12- 场景工程化与批量渲染
13- 贯穿实战：完整复刻项目
```

比初级版（10 篇）稍长，因为要承载脚本代码。

## 需要用户确认的两点

1. **是否直接开写？** 还是先出一份详细大纲（含每章小节标题、示例代码清单）供审阅？
2. **是否与初级版同仓库？**
   - 方案 A：新建独立仓库 `blender-advanced-guide`
   - 方案 B：并入现有 `blender-beginner-guide` 的 `advanced/` 目录

我倾向 **方案 A + 独立仓库**，因为进阶版和入门版的读者、节奏、代码密度差别很大，混在一起会让入门读者望而却步。
