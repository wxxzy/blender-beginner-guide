# 03 · 程序化曲面：中式起翘屋面

## 概念

中式屋顶不是简单的斜面——它有**曲线起翘**（翼角上翘）、**曲面过渡**、**正脊**。手工建模极难，程序化生成却只需一个公式。

核心思路：**给定一个参数 t（0→1，从屋脊到檐口），算出该位置的坐标**。曲面就是这些点的网格。

```
z = z_ridge - (z_ridge - z_eave) * (1 - (1 - t) ** 1.7)
                        ↑                    ↑
                   基础坡度            幂次控制曲线形状
```

`t` 从 0（屋脊）到 1（檐口）。幂次 1.7 让靠近屋脊处更平缓、靠近檐口更陡——这正是中式屋面的比例。

## 完整实现：起翘屋面

```python
import bpy, bmesh, math

def add_roof_surface(mb, cx, cy, wy, dx, z_eave, z_ridge,
                     ov=0.85, curl=0.55, mat=0,
                     seg_t=7, seg_y=5):
    """生成一片起翘屋面。

    cx, cy   —— 屋面中心
    wy, dx   —— 屋面的 y 方向宽度 / x 方向半跨度
    z_eave   —— 檐口高度
    z_ridge  —— 屋脊高度
    ov       —— 出檐（挑出屋面主体的长度）
    curl     —— 翼角起翘幅度
    """
    half = dx / 2 + ov
    y0 = cy - wy / 2 - 0.45
    y1 = cy + wy / 2 + 0.45

    for s in (-1, 1):          # 屋面左右两坡
        rows = []
        for j in range(seg_y + 1):
            y = y0 + (y1 - y0) * j / seg_y
            row = []
            for i in range(seg_t + 1):
                t = i / seg_t                                  # 0=脊 1=檐

                # ① 基础坡度（幂次曲线）
                x = cx + s * half * t
                z = z_ridge - (z_ridge - z_eave) * (1 - (1 - t) ** 1.7)

                # ② 翼角起翘：只在靠近山墙（y 两端）且靠近檐口时生效
                ey = max(0.0, abs(y - cy) - (wy / 2 + 0.45 - 1.05)) / 1.05
                z += curl * (ey ** 2.2) * (t ** 2.4)

                row.append((x, y, z))
            rows.append(row)

        # mb.grid 由网格点阵直接生成面片
        mb.grid(rows, mat=mat, smooth=True, flip=(s < 0))
```

**三个设计要点**：

1. **幂次曲线控坡度** —— `(1-t)**1.7` 让曲面自然过渡
2. **起翘用双因子相乘** —— `ey**2.2 * t**2.4`：只在"靠近山墙"且"靠近檐口"时才翘，中部不起翘。这就是中式翼角的形态特征
3. **`flip` 处理法线** —— 左右两坡方向相反，必须翻转其中一坡，否则法线朝内，渲染全黑

## bmesh 的网格辅助函数

上面的 `mb.grid()` 是自定义辅助函数。标准 bmesh 没有直接的"点阵转面片"，常见两种做法：

### 做法 A：用 `from_pydata` 一次性建

```python
def mesh_from_grid(name, rows):
    """rows 是二维点阵 [[(x,y,z), ...], [...]]，行=列。"""
    verts = [v for row in rows for v in row]
    ncol = len(rows[0])
    faces = []
    for j in range(len(rows) - 1):
        for i in range(ncol - 1):
            a = j * ncol + i
            b = a + 1
            c = (j + 1) * ncol + i + 1
            d = (j + 1) * ncol + i
            faces.append((a, b, c, d))

    me = bpy.data.meshes.new(name)
    me.from_pydata(verts, [], faces)
    me.update()
    return me
```

### 做法 B：用 `bmesh.ops.grid_fill`（推荐）

Blender 内置的网格填充操作，能处理任意点阵：

```python
def grid_to_object(name, rows, smooth=True):
    me = bpy.data.meshes.new(name)
    bm = bmesh.new()
    verts = [bm.verts.new(v) for row in rows for v in row]
    bm.verts.ensure_lookup_table()

    ncol = len(rows[0])
    n = len(verts)
    grid_edges = []
    for j in range(len(rows) - 1):
        for i in range(ncol - 1):
            a = j * ncol + i
            bmesh.ops.contextual_create(bm, geom=verts[a:a+2])

    bmesh.ops.remove_doubles(bm, verts=bm.verts[:], dist=1e-4)
    bm.normal_update()
    bm.to_mesh(me)
    bm.free()
    return me
```

> 💡 实践中最稳的是**做法 A + `remove_doubles`**：先用 `from_pydata` 建四边形面，再清理可能的重复点。

## 实战：完整的中式屋面组件

江南水巷的屋顶由三部分组成：屋面 + 瓦当（檐口滴水）+ 正脊。

```python
import bpy, bmesh, math

def build_roof(name, cx, cy, width=6.0, depth=5.0,
               z_eave=3.2, z_ridge=4.6, curl=0.55):
    me = bpy.data.meshes.new(name)
    bm = bmesh.new()

    half = width / 2 + 0.85
    y0 = cy - depth / 2 - 0.45
    y1 = cy + depth / 2 + 0.45

    # ① 左右两坡屋面
    for s in (-1, 1):
        rows = []
        for j in range(6):
            y = y0 + (y1 - y0) * j / 5
            row = []
            for i in range(8):
                t = i / 7
                x = cx + s * half * t
                z = z_ridge - (z_ridge - z_eave) * (1 - (1 - t) ** 1.7)
                ey = max(0.0, abs(y - cy) - (depth / 2 + 0.45 - 1.05)) / 1.05
                z += curl * (ey ** 2.2) * (t ** 2.4)
                row.append((x, y, z))
            rows.append(row)

        # 建面片
        base = len(bm.verts)
        vs = [bm.verts.new(v) for row in rows for v in row]
        for j in range(5):
            for i in range(7):
                a = j * 8 + i
                quad = (vs[a], vs[a+1], vs[a+8+1], vs[a+8])
                if s < 0:
                    quad = tuple(reversed(quad))
                bm.faces.new(quad)

    # ② 檐口瓦当：一排圆头滴水（决定剪影的关键细节）
    y = y0 + 0.12
    while y < y1 - 0.05:
        for s in (-1, 1):
            x = cx + s * half
            bmesh.ops.create_cone(
                bm, cap_ends=True, cap_tris=False, segments=8,
                radius1=0.058, radius2=0.058, depth=0.17,
                matrix=__import__("mathutils").Matrix.Translation(
                    (x, y, z_eave - 0.03)
                )
            )
        y += 0.34

    bm.normal_update()
    bm.to_mesh(me)
    bm.free()

    obj = bpy.data.objects.new(name, me)
    bpy.context.scene.collection.objects.link(obj)
    return obj

roof = build_roof("Roof", cx=0, cy=0)
print("ROOF verts =", len(roof.data.vertices))
```

**验证**：输出顶点数，场景里出现一片带翼角起翘、带瓦当的屋面。

上图是脚本真实渲染的结果：一排参数化生成的屋顶，每栋的宽度、檐高、脊高、起翘幅度都有随机差异，但都保持了中式的翼角形态。

> ⚠️ **踩坑：多坡共用一个 bmesh 时的索引错位**
>
> 上面代码里，屋面有左右两坡，都往同一个 `bm` 里加顶点。如果写：
> ```python
> base = len(bm.verts)          # 全局偏移
> vs = [bm.verts.new(v) for row in rows for v in row]
> a = base + j * 8 + i          # ← 错误：base 是全局的，vs 是局部的
> ```
> 第二坡时 `base` 已经很大，而 `vs` 索引从 0 开始，必然越界报 `IndexError: list index out of range`。
>
> **正确做法**：`vs` 是本坡的列表，就用局部索引 `a = j * 8 + i`，不要加全局偏移。

## 参数化：让屋顶可调

把关键参数抽出来，就能生成一整排不同尺寸的屋顶：

```python
def make_roof_row(n, spacing, seed=0):
    """沿 x 方向生成 n 栋房子的屋顶，尺寸带随机变化。"""
    rng = random.Random(seed)
    for i in range(n):
        w = rng.uniform(5.0, 7.5)
        d = rng.uniform(4.5, 6.0)
        ze = rng.uniform(3.0, 3.6)
        zr = ze + rng.uniform(1.2, 1.7)
        curl = rng.uniform(0.4, 0.75)

        build_roof(
            name=f"Roof_{i:02d}",
            cx=spacing * i, cy=0,
            width=w, depth=d,
            z_eave=ze, z_ridge=zr, curl=curl,
        )
```

**这就是从"做一个"到"做一千个"的跃迁**：写好一次参数化的 `build_roof`，后面只是循环。

## 曲面的平滑着色

程序化生成的曲面要开启平滑，否则会看到明显的多边形折线：

```python
for p in obj.data.polygons:
    p.use_smooth = True
```

但这会让**本该硬朗的边**也变圆。解决方案是加"自动平滑"（Weighted Normal 或 Edge Split）：

```python
# Blender 4.1+ 用"平滑按角度"操作符
bpy.ops.object.shade_smooth_by_angle(angle=math.radians(30))
```

## 本章要点回顾

- 曲面 = 参数化点阵，核心是"给定 t 求坐标"
- 幂次 `(1-t)**n` 控制基础坡度曲线
- 中式翼角起翘 = "靠近山墙"因子 × "靠近檐口"因子
- 左右两坡要 `flip` 否则法线朝内
- 一次性建网格用 `from_pydata`，之后 `remove_doubles` 清理
- 平滑 + 按角度锐边，是程序化曲面的标准收尾
