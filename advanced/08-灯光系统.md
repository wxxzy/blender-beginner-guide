# 08 · 灯光系统

## 概念

三维渲染的本质是**解算光在物体表面的反射**。理解光源类型，就理解了画面为什么长这样。

| 光源类型 | 物理对应 | 特性 |
|---------|---------|------|
| Point 点光 | 灯泡 | 从一点向四面发散，衰减明显 |
| Sun 太阳光 | 平行光 | 无限远，所有方向强度相同，无衰减 |
| Spot 聚光 | 射灯 | 锥形照射，可聚焦 |
| Area 面光 | 柔光箱 | 有面积，阴影柔和（**室内首选**） |

**关键区别**：点光/聚光有距离衰减，太阳光没有。面光有面积，阴影边缘最软。

## 灯光的三个核心属性

```python
light = bpy.data.lights.new("MyLight", "POINT")
light.energy = 100.0          # 功率（瓦特）
light.color = (1.0, 0.85, 0.7)  # 颜色
light.shadow_soft_size = 0.3    # 阴影柔和度（点光/面光）
```

**`shadow_soft_size`** 是最容易被忽略但极重要的参数——它决定光源"有多大"。值越大，阴影边缘越软。

## 颜色与色温

光色影响整个画面的情绪。物理上用**色温（K）**描述：

| 色温 | 颜色 | 感觉 |
|------|------|------|
| 2000K | 橙红 | 烛光、暖黄 |
| 3200K | 暖白 | 家用灯泡 |
| 5500K | 中性白 | 摄影棚标准 |
| 7000K | 冷白 | 阴天 |
| 9000K | 蓝白 | 月光、清晨 |

**夜景的关键手法是冷暖对比**：
- 环境光（月光、天光）用**冷色**
- 实用光源（灯笼、招牌）用**暖色**

冷暖对撞能让画面立刻有层次。

```python
def kelvin_to_rgb(k):
    """简化的色温 → RGB 转换（近似，够用）。"""
    t = k / 100.0
    if t <= 66:
        r = 255
        g = 99.4708025861 * math.log(t) - 161.1195681661
    else:
        r = 329.698727446 * ((t - 60) ** -0.1332047592)
        g = 288.1221695283 * ((t - 60) ** -0.0755148492)
    if t >= 66:
        b = 255
    elif t <= 19:
        b = 0
    else:
        b = 138.5177312231 * math.log(t - 10) - 305.0447927307
    return tuple(min(1.0, max(0.0, c / 255.0)) for c in (r, g, b))
```

> ⚠️ 灯光颜色也要转线性空间（和材质颜色一样）。

## 布光的三个角色

好画面需要三种光的分工：

| 角色 | 作用 | 特征 |
|------|------|------|
| **主光 Key** | 确立形体与明暗关系 | 最亮，决定阴影方向 |
| **补光 Fill** | 提亮暗部，减小反差 | 较暗，柔和，无硬阴影 |
| **轮廓光 Rim** | 勾勒物体边缘，分离背景 | 从侧后方，窄而亮 |

**夜景的布光逻辑不同**：主光是月亮（冷、弱），画面亮点来自大量实用光源（灯笼、招牌、窗）。

## 实战：江南水巷的灯光系统

```python
def add_point_light(coll, name, loc, energy, color="#ff8a3c",
                    radius=0.35, shadow=False):
    ld = bpy.data.lights.new(name, "POINT")
    ld.energy = energy
    ld.color = hex_to_linear(color)[:3]
    ld.shadow_soft_size = radius
    ld.use_shadow = shadow
    ob = bpy.data.objects.new(name, ld)
    ob.location = loc
    coll.objects.link(ob)
    return ob


def build_lights(coll):
    # ① 月光：太阳光，冷色，负责整体明暗结构
    sd = bpy.data.lights.new("Moon", "SUN")
    sd.energy = 0.8
    sd.color = (0.60, 0.71, 1.0)      # 冷蓝
    sd.angle = math.radians(8)          # 角度大 = 阴影更软
    sd.use_shadow = True
    sun = bpy.data.objects.new("Moon", sd)
    sun.rotation_euler = (math.radians(62), 0, math.radians(-32))
    coll.objects.link(sun)

    # ② 天光：面光，大面积、无阴影，负责环境亮度
    ad = bpy.data.lights.new("SkyFill", "AREA")
    ad.energy = 110
    ad.size = 26                       # 巨大的柔光源
    ad.color = (0.36, 0.44, 0.72)      # 冷蓝紫
    ad.use_shadow = False               # 不投影，纯补光
    a = bpy.data.objects.new("SkyFill", ad)
    a.location = (0, -10, 18)
    coll.objects.link(a)

    # ③ 沿河灯阵：暖色点光，间距 8m
    y = -38.0
    i = 0
    while y < 36.0:
        for side in (-1, 1):
            add_point_light(coll, f"PL_{i:02d}",
                            (side * (RIVER_HALF - 0.9), y, 4.3),
                            70.0, "#ff8d45", 0.9, shadow=(i % 7 == 0))
            i += 1
        y += 8.0

    # ④ 桥洞附近重点光
    add_point_light(coll, "PL_BridgeA", (-1.6, BRIDGE_Y - 2.8, 2.6), 30, "#ff9450", 1.6, True)
    add_point_light(coll, "PL_BridgeB", (2.4, BRIDGE_Y - 2.2, 6.0), 22, "#ffa05c", 1.2, False)
    add_point_light(coll, "PL_Arch",    (0.2, BRIDGE_Y, 1.75),       22, "#ffa060", 0.9, False)

    # ⑤ 冷色点缀，打破单调
    add_point_light(coll, "PL_Cool", (-RIVER_HALF + 0.6, -2.0, 3.4), 18, "#7fd0ff", 0.6)
```

### 关键优化：只有部分灯投影

```python
shadow=(i % 7 == 0)     # 每 7 盏只有 1 盏投影
```

点光的阴影计算很贵。远处的小灯投不投影几乎看不出差别，但能省下大量渲染时间。**这是夜景渲染最有效的优化之一。**

## 补光与实景光

```python
# 面光：适合当补光
ad = bpy.data.lights.new("Fill", "AREA")
ad.energy = 300
ad.size = 8          # 尺寸越大越柔
ad.use_shadow = False

# 点光：适合当实用光源（灯笼）
pd = bpy.data.lights.new("Lamp", "POINT")
pd.energy = 40
pd.shadow_soft_size = 0.15   # 小 = 锐利的小灯泡
pd.use_shadow = True
```

## 世界背景（环境光）

世界环境给整个场景一个基础亮度：

```python
world = bpy.context.scene.world
if world is None:
    world = bpy.data.worlds.new("World")
    bpy.context.scene.world = world
world.use_nodes = True
bg = world.node_tree.nodes.get("Background")
bg.inputs[0].default_value = (0.62, 0.68, 0.76, 1.0)   # 夜空蓝
bg.inputs[1].default_value = 1.1                        # 强度
```

**夜晚也要有环境光**，否则暗部会纯黑，什么都看不见。这是新手最容易忽略的一点。

## 曝光与色调映射

```python
sc.view_settings.exposure = 2.35       # 曝光（以 stops 为单位）
sc.view_settings.view_transform = "AgX" # 或 "Standard" / "Filmic"
sc.view_settings.look = "NONE"         # 5.2 只有 NONE 可用
```

**曝光是最直接的调亮/调暗手段**，比反复改灯光强度方便得多。`+1` stop 相当于亮度翻倍。

> ⚠️ Blender 5.2 的 `view_settings.look` **只有 `NONE` 可用**，旧教程里的 `Medium High Contrast` 等会报错。

## 验证布光的三个问题

1. **主体亮还是暗？** 主光够不够照到主体？
2. **暗部有信息吗？** 补光和世界光够不够？
3. **颜色有层次吗？** 冷暖对比明显吗？

用渲染模式（`Z` → Rendered）实时看，不要靠猜。

## 本章要点回顾

- 面光阴影最软，室内首选；太阳光无衰减，负责整体结构
- **夜景靠冷暖对比**：环境冷、实用光暖
- `shadow_soft_size` 控制阴影柔和度
- **只有 1/7 的灯投影**，渲染时间大减
- 夜晚必须有环境光，否则暗部纯黑
- 曝光用 `view_settings.exposure` 调，比改灯光方便
- 5.2 的 `view_settings.look` 只有 `NONE`
