# 05 · 几何节点入门

## 概念

前四章都是"用代码描述几何"。几何节点（Geometry Nodes）是另一条路：**用可视化节点搭出一套数据处理流程**，像搭电路一样。

| | bmesh / 修改器 | 几何节点 |
|---|---|---|
| 描述方式 | 代码 | 节点连线 |
| 强项 | 精确的造型 | 大规模分布、程序化变形 |
| 调整方式 | 改代码重跑 | 拖节点，实时更新 |
| 适合 | 做几个零件 | 撒一万个东西 |

**核心思想**：几何节点处理的是"数据流"——网格进，经过一连串节点处理，几何出。

```
输入网格 → [分布式点] → [实例化] → [变换] → 输出网格
```

## 创建节点组

```python
import bpy

def new_geo_group(name="GeoGroup"):
    ng = bpy.data.node_groups.new(name, "GeometryNodeTree")

    # 接口（Blender 4.0+ 用 interface，不再用 inputs/outputs）
    ng.interface.new_socket("Geometry", in_out="INPUT",
                            socket_type="NodeSocketGeometry")
    ng.interface.new_socket("Geometry", in_out="OUTPUT",
                            socket_type="NodeSocketGeometry")
    return ng

ng = new_geo_group("ScatterTest")

gin  = ng.nodes.new("NodeGroupInput")
gout = ng.nodes.new("NodeGroupOutput")
gin.location  = (-600, 0)
gout.location = (600, 0)
```

> ⚠️ **Blender 4.0+ 的 API 变化**：
> - 旧版：`ng.inputs.new(...)` / `ng.outputs.new(...)`
> - 新版：`ng.interface.new_socket(name, in_out="INPUT"|"OUTPUT", socket_type=...)`
>
> 用旧 API 会报 `AttributeError`。

## 完整示例：在面上随机撒实例

这是几何节点最经典的用法——**把一个物体随机撒在另一个表面上**。

```python
def build_scatter_group(name="Scatter", density=3.0, scale=0.12, seed=7):
    ng = bpy.data.node_groups.new(name, "GeometryNodeTree")
    ng.interface.new_socket("Geometry", in_out="INPUT",
                            socket_type="NodeSocketGeometry")
    ng.interface.new_socket("Geometry", in_out="OUTPUT",
                            socket_type="NodeSocketGeometry")

    gin  = ng.nodes.new("NodeGroupInput");  gin.location  = (-800, 0)
    gout = ng.nodes.new("NodeGroupOutput"); gout.location = (800, 0)

    # ① 在面上分布式点
    dist = ng.nodes.new("GeometryNodeDistributePointsOnFaces")
    dist.location = (-450, 0)
    dist.distribute_method = "RANDOM"
    dist.inputs["Density"].default_value = density
    dist.inputs["Seed"].default_value = int(seed)      # ← 注意是 int

    # ② 做一个"瓦片"实例（一条网格线）
    line = ng.nodes.new("GeometryNodeMeshLine")
    line.location = (-450, -320)
    line.mode = "OFFSET"
    line.inputs["Count"].default_value = 8
    line.inputs["Offset"].default_value = (0.09, 0.0, 0.0)

    # ③ 在点上实例化
    inst = ng.nodes.new("GeometryNodeInstanceOnPoints")
    inst.location = (0, 0)
    inst.inputs["Pick Instance"].default_value = True

    # ④ 缩放实例
    scl = ng.nodes.new("GeometryNodeScaleInstances")
    scl.location = (350, 0)
    scl.inputs["Scale"].default_value = (scale, scale, scale)

    # 连线
    ng.links.new(gin.outputs["Geometry"], dist.inputs["Mesh"])
    ng.links.new(dist.outputs["Points"], inst.inputs["Points"])
    ng.links.new(line.outputs["Mesh"], inst.inputs["Instance"])
    ng.links.new(inst.outputs["Instances"], scl.inputs["Instances"])
    ng.links.new(scl.outputs["Instances"], gout.inputs["Geometry"])

    return ng

ng = build_scatter_group()
print("GN built, nodes =", len(ng.nodes))
```

**验证**：输出 `GN built, nodes = 6`。

> ⚠️ **踩坑：Seed 必须传整数**
>
> `dist.inputs["Seed"].default_value = 7.0` 会报：
> `TypeError: NodeSocketInt.default_value expected an int type, not float`
>
> 用 `int(seed)` 转换。

## 常用几何节点

### 分布类

| 节点 | 作用 |
|------|------|
| `Distribute Points on Faces` | 在面上按随机/泊松松分布点 |
| `Distribute Points in Volume` | 在体积内撒点 |
| `Instance on Points` | 在点上放实例 |
| `Instance on Faces` | 直接在面上放实例（不需要先分布点） |

### 变换类

| 节点 | 作用 |
|------|------|
| `Set Position` | 移动/扰动点位置 |
| `Scale Instances` | 缩放实例 |
| `Rotate Instances` | 旋转实例 |
| `Translate Instances` | 平移实例 |
| `Join Geometry` | 合并多个几何流 |
| `Delete Geometry` | 按选择删除 |

### 生成类

| 节点 | 作用 |
|------|------|
| `Mesh Line` | 生成线段 |
| `Mesh Grid` | 生成网格面 |
| `Mesh Circle` | 生成圆 |
| `Cube` / `UV Sphere` / `Cylinder` | 生成基本体 |
| `Curve to Mesh` | 曲线转网格 |

### 属性类

| 节点 | 作用 |
|------|------|
| `Store Named Attribute` | 存自定义属性 |
| `Named Attribute` | 读取属性 |
| `Capture Attribute` | 捕获属性并继续处理 |

## 实战：沿曲线分布灯笼

```python
def build_along_curve(name, count=12):
    ng = bpy.data.node_groups.new(name, "GeometryNodeTree")
    ng.interface.new_socket("Geometry", in_out="INPUT",
                            socket_type="NodeSocketGeometry")
    ng.interface.new_socket("Geometry", in_out="OUTPUT",
                            socket_type="NodeSocketGeometry")

    gin  = ng.nodes.new("NodeGroupInput");  gin.location  = (-800, 0)
    gout = ng.nodes.new("NodeGroupOutput"); gout.location = (800, 0)

    # 曲线转网格（拿到边）
    c2m = ng.nodes.new("GeometryNodeCurveToMesh")
    c2m.location = (-600, 200)

    # 边转点
    e2p = ng.nodes.new("GeometryNodeMeshToPoints")
    e2p.location = (-400, 200)
    e2p.mode = "EDGES"

    # 在线上分布点
    dist = ng.nodes.new("GeometryNodeDistributePointsOnCurve")
    dist.location = (-200, 200)
    dist.inputs["Count"].default_value = count

    # 实例化
    inst = ng.nodes.new("GeometryNodeInstanceOnPoints")
    inst.location = (100, 200)
    inst.inputs["Pick Instance"].default_value = True

    # 对齐到曲线切线方向
    align = ng.nodes.new("GeometryNodeAlignRotationToVector")
    align.location = (350, 200)

    ng.links.new(gin.outputs["Geometry"], c2m.inputs["Curve"])
    ng.links.new(c2m.outputs["Mesh"], e2p.inputs["Mesh"])
    ng.links.new(e2p.outputs["Points"], dist.inputs["Curve"])
    ng.links.new(dist.outputs["Points"], inst.inputs["Points"])
    ng.links.new(inst.outputs["Instances"], align.inputs["Geometry"])
    ng.links.new(align.outputs["Geometry"], gout.inputs["Geometry"])
    return ng
```

## 什么时候用几何节点而不是脚本

**用几何节点**：
- 需要实时调参数（拖滑块就变）
- 结构是"流式处理"（分布 → 变形 → 实例化）
- 想让非程序员也能改

**用脚本**：
- 需要精确的数值控制、复杂逻辑分支
- 需要和其他系统（数据生成、批量处理）集成
- 一次性生成，结果固定

**两者结合**：用脚本搭骨架，用几何节点做细节（如散布、抖动）。

## 在界面里编辑节点组

脚本搭好节点组后，可以在 Blender 界面里继续调整：

1. 选中物体 → 修改器面板 → 几何节点修改器
2. 点"编辑"打开节点编辑器
3. 拖动节点、连线、调参数，实时看到效果
4. **把某个节点组保存成资产**（资产浏览器），下次直接复用

## 本章要点回顾

- 几何节点是"数据流"思维：进 → 处理 → 出
- **4.0+ 用 `ng.interface.new_socket()`** 建接口
- 经典组合：`Distribute Points on Faces` → `Instance on Points` → `Scale/Rotate Instances`
- `Seed` 是 int socket，传 float 会报错
- 用脚本搭初始结构，用界面做精细调整——这是最高效的工作流
