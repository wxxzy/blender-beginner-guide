# 06 · 优化导出：让模型能用在别处

最后一步不是渲染，而是让模型**干净、可复用**。打开 [阶段 6 快照](blends/06_final.blend) 对照。

## 步骤一：清理拓扑

1. 进编辑模式，`Select → Select All by Trait → Non Manifold`，结果应为空；
2. `Shift + N` 重算法线，确保全部朝外；
3. `Merge by Distance`，阈值设 **0.001**，清掉重叠顶点；
4. 检查有没有悬空的边或孤立顶点，删掉。

> ⚠️ 非流形网格在别的软件里会出各种怪问题：破面、法线翻转、无法细分。导出前一定要查一遍。

## 步骤二：减面

给苹果加 `Decimate` 修改器，比例从 **0.5** 开始试：

1. 复制一份渲染对比，看轮廓有没有变；
2. 肩部和高光区最敏感，那里一旦出现棱角就说明减太狠；
3. 满意后应用修改器。

给游戏或实时引擎用时，建议做多级 LOD：远景用低模、近景用高模。

## 步骤三：打包资源

`File → External Data → Pack Resources`，把贴图打包进 `.blend`。

> ⚠️ 不打包的话，换台电脑打开就是白色模型——贴图路径还在原机器上。

## 步骤四：导出

`File → Export → glTF 2.0`，勾选：

- Y-up（Blender 默认 Z-up，多数引擎用 Y-up）
- Apply Modifiers
- Include Materials

也可以按需求选 FBX 或 OBJ。导出后重新导入一次，确认法线不反、贴图没丢、朝向正确。

## 步骤五：最终出图

回到 [05 · 灯光渲染](05-灯光渲染.md) 的设置，按 `F12` 渲染，输出见 [最终效果图](images/fig_final.png)。

## 案例总结

六步走完，你实际完成了一个完整的写实静物：

| 阶段 | 你做的事 | 形成的能力 |
|------|---------|-----------|
| 01 参考分析 | 量比例、拆体块 | 不再"看着捏" |
| 02 基础形体 | 低模、比例编辑、应用缩放 | 快速起形 |
| 03 拓扑雕刻 | 环线、细分、位移 | 可控的高模 |
| 04 材质贴图 | 程序化渐变与毛孔 | 不靠贴图也能出质感 |
| 05 灯光渲染 | 三点布光、EEVEE | 用光讲清形体 |
| 06 优化导出 | 清理、减面、打包 | 交付可用模型 |

这套方法可以直接迁移到任何静物：换个参考图，重复这六步即可。
