# 02 · 基础形体：266 个顶点做出剪影

这一阶段只做**剪影和体块**。不要上色、不要加花纹、不要纠结表面细节——那些是后面几步的事。

打开 [阶段 2 快照](blends/02_blockout.blend)，选中 `Apple_Blockout`，按 `Tab` 进编辑模式，`Z → Wireframe` 看线框。

## 步骤一：从 UV Sphere 起步

1. `Add → Mesh → UV Sphere`，左下角弹出的面板里把 **Segments 设为 24、Ring Count 设为 12**。
2. 段数和环数刻意取低——体块阶段顶点越少，越容易大刀阔斧地改形状。
3. `Tab` 进编辑模式，`A` 全选，确认模型是光滑着色还是平面着色都无所谓，先看剪影。

> 本案例快照的体块共 266 个顶点，就是这个参数下生成的。

## 步骤二：用比例编辑改大形

比例编辑（Proportional Editing）是做有机形状最顺手的工具：

1. 按 `O` 开启比例编辑，滚轮调整影响半径；
2. 选上半部分顶点，按 `S` 向外拉宽**肩部**；
3. 选底部几圈顶点，`S` 向内收窄，让轮廓上宽下窄；
4. 随时按小键盘 `1` / `3` 切正交视图检查剪影。

> ⚠️ **先大形后细节**。此时如果发现整体比例不对（比如太瘦），直接改，代价很低。等到加了细分和材质再改，所有工作都要推翻重来。

## 步骤三：压出顶部与底部凹坑

1. `Alt + 左键` 点选顶部第一圈边，快速选中一整环顶点；
2. 按 `S` 略微缩小，再按 `G`、`Z` 向下压，做出顶部凹坑；
3. 底部同样选环、缩小、向上轻推，做出更浅的底坑。

## 步骤四：应用缩放

这一步不能省：

1. 回到物体模式，`Ctrl + A → Scale`。

> ⚠️ **非等比缩放不应用，后面全出问题**：细分修改器会把压扁的形状放大偏差，法线计算也会歪，布尔运算更容易失败。养成 `Ctrl+A` 的习惯。

## 本阶段自检

- 按 `Z → Solid` 切实体视图，关掉材质只看剪影——能一眼认出是苹果，不是球；
- 顶点数仍然很少，没有多余的点线面；
- 缩放已应用（N 面板里 Scale 显示 1, 1, 1）。

→ 完成后进入 [03 · 拓扑与雕刻](03-拓扑与雕刻.md)。
