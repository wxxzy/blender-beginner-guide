# 06 · 优化导出：硬表面的交付检查

打开 [阶段 6 快照](blends/06_final.blend)。

## 步骤一：材质槽检查（硬表面必做）

逐个选中物体，在 Material Properties 里确认**第一个槽不是空的**。布尔运算最容易留下空槽，不检查就会出现"明明赋了材质却是白色"的问题。

## 步骤二：拓扑检查

1. 编辑模式下 `Select → Select All by Trait → Non Manifold`，结果应为空；
2. `Shift+N` 重算法线；
3. 检查倒角边缘有没有自交，尤其是圆孔与面板边界处。

> ⚠️ 布尔后的边缘拓扑通常不漂亮，但只要非流形为空、法线正确、渲染无破面，就不必强行重拓扑。硬表面的面数通常可控。

## 步骤三：减面与 LOD

- 旋钮滚花、螺丝这类重复小件：远处可直接用低模替代；
- 机身倒角 Segments 4 在近景必要，远景降到 2 也看不出差别；
- 按用途做多级 LOD，别让一个模型通吃所有距离。

## 步骤四：导出

`File → External Data → Pack Resources` 后，用 glTF 2.0 导出（Y-up、Apply Modifiers、Include Materials）。

重新导入一次，确认：木纹没丢、金属度正确、透明玻璃没变成白板。

## 案例总结

| 阶段 | 你做的事 | 形成的能力 |
|------|---------|-----------|
| 01 参考分析 | 拆四个功能模块、量比例 | 硬表面结构思维 |
| 02 基础形体 | 盒子圆柱拼装 | 快速搭大形 |
| 03 拓扑细节 | 倒角、布尔、加权法线、滚花 | 硬表面核心工艺 |
| 04 材质贴图 | 木纹、网布、黄铜、玻璃 | 多材质对比控制 |
| 05 灯光渲染 | 三点布光、构图留白 | 用光讲清材质 |
| 06 优化导出 | 材质槽、非流形、LOD | 可交付模型 |

两个案例做下来：[红苹果](../apple/README.md) 的有机曲面 + 本案例的硬表面，就覆盖了绝大多数静物建模场景。下一步可以进入 [进阶版](../../advanced/README.md)，用脚本把这套流程自动化。
