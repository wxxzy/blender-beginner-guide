# 04 · 材质贴图：六种材质放一起调

打开 [阶段 4 快照](blends/04_material.blend)，进 Shading 工作区逐个看。

## 步骤一：胡桃木

1. `TexCoord.Generated` → `Mapping`（Z 方向缩放 1.4）；
2. `Wave` 纹理 BANDS 方向 Z，Scale 7，Distortion 4 → 木纹走向；
3. `Noise` Scale 5 → Bump，Strength 0.16 / Distance 0.006；
4. `ColorRamp` 四段深棕到浅棕 → Base Color；
5. Roughness 0.42，Coat Weight 0.18。

> ⚠️ 木纹方向靠 Mapping 和 Wave 的 Bands Direction 控制。方向不对，再好看的纹理也像塑料。

## 步骤二：胶木面板

深色 `(0.055, 0.05, 0.045)`，Roughness 0.40，叠一个 Scale 120 的 Noise → Bump 做细微颗粒。

> ⚠️ 面板发白通常不是灯光问题，而是**材质槽为空**（见 03 章）。先查槽，再查灯。

## 步骤三：喇叭网布

两组 `Wave` 纹理（X 方向 + Z 方向，Scale 70）相乘 → Bump，Strength 0.45 / Distance 0.004。Base Color 用极深的灰棕。

交叉波纹能织出网格感，比用几千个实体孔省面数得多。

## 步骤四：黄铜与玻璃

- **黄铜**：Base Color `(0.66, 0.48, 0.20)`，Metallic 0.82，Roughness 0.32，叠 Noise Bump 做旧；
- **玻璃**：Roughness 0.06，IOR 1.46，Transmission Weight 0.72。

> ⚠️ Metallic 给到 0.8 以上才像金属，但漫反射颜色会几乎消失，所以黄铜的 Base Color 要调亮一点才不会发黑。

刻度盘米色、数字黑色、指针暗红、支脚橡胶黑——都是简单材质，重点是和主材质形成对比。

## 本阶段自检

- 木壳有方向清晰的纹理，不是均匀噪声；
- 面板是深色，不是白色；
- 黄铜旋钮有金属高光，网布是哑光；
- 玻璃能透出刻度。
