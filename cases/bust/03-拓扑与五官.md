# 03 · 拓扑与五官：参数化塑形 + 骨架

本案例最重要的一章。打开 [阶段 3 快照](blends/03_topology.blend)。

## 步骤一：参数化头部网格

头部由球面坐标生成：`theta` 从 0 到 π，`phi` 从 0 到 2π。每个顶点的位置由基础椭球 + 高斯函数修正得到：

```
x = RX * sin(theta) * cos(phi) * jaw_taper
y = RY * sin(theta) * sin(phi) - feature_displacement
z = RZ * cos(theta) + HEAD_Z
```

`feature_displacement` 由多个高斯函数叠加：

- 鼻梁 / 鼻尖：中心 `(0, -0.04)`，宽 0.13 × 0.26；
- 眉弓：中心 `(±0.26, 0.30)`；
- 眼窝：负值高斯，把眼眶压进去；
- 颧骨、嘴部、下巴：各自一个高斯。

> ⚠️ 所有特征都乘一个 `front = max(0, -dy)^2` 权重，只影响正面。不做这一步，后脑勺也会被"长出鼻子"。

## 步骤二：拓扑质量

- 网格以四边面为主；
- 极点只在头顶与下巴（球面参数化的天然结果）；
- 加 Subdivision Surface，视口 1 级 / 渲染 2 级。

> ⚠️ 面部极点不能落在眼睛或嘴角——那些区域动画时会拉伸变形。球面 UV 的极点正好在头顶下巴，是安全位置。

## 步骤三：五官组件

- **眼球**：球体压扁（Y 方向 0.72），虹膜和瞳孔是越来越靠前的小球；
- **眼睑 / 眉毛 / 嘴唇**：用贝塞尔曲线 + `Bevel Depth` 做细管，比建面片省事；
- **鼻头 / 鼻翼**：小球补齐高斯塑形做不出的圆润端部；
- **耳朵**：压扁球体 + 一条内耳曲线；
- **发帽**：独立参数化球面，前额发际线低、后脑高，避免"锅盖"感。

> ⚠️ 发丝曲线不要飘在头顶。第一版发丝控制点设得太高，渲染出来像天线。要么贴合发帽表面，要么干脆不加。

## 步骤四：预留骨架

在 Outliner 里看 `Bust_Rig`，骨骼链：

```
Root → Spine → Neck → Head
```

这是**层级占位**，还没做蒙皮。它的意义是：后面加顶点组和 Armature 修改器时，骨架已经就位。

## 本阶段自检

- 头部是连续四边面网格，极点位置正确；
- 五官左右对称、位置符合三庭五眼；
- 发帽贴合头骨，没有悬空曲线；
- 骨骼链存在且层级正确。
