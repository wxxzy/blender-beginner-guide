# 02 · 基础形体：用角度算径向布局

打开 [阶段 2 快照](blends/02_blockout.blend)。

## 步骤一：机身占位

`Cube` 或 `Cylinder` 做一个 `(1.0, 1.0, 0.35)` 的盒子，放在 `z = 1.55`，代表中央舱。

## 步骤二：四臂径向重复

对每个角度 `a ∈ {45, 135, 225, 315}`：

```
t = radians(a)
arm.pos = (1.05*cos(t), 1.05*sin(t), BODY_Z)
arm.rotation_z = t
motor.pos = (1.75*cos(t), 1.75*sin(t), BODY_Z + 0.1)
```

盒子长轴沿 X，旋转 Z 到 `t` 就指向辐射方向。这一步是本节最值钱的技巧：**用极坐标布置重复零件**。

> ⚠️ `math.radians()` 别忘了。Blender 内部用弧度，界面显示的是度。混用会让机臂乱飞。

## 步骤三：自检布局

- 顶视图看，四个电机应在正方形的四个角上；
- 机臂从机身边缘伸出，不要穿进机身内部；
- 四个电机高度一致。
