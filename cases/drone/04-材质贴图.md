# 04 · 材质贴图：暗色科幻的分区逻辑

打开 [阶段 4 快照](blends/04_material.blend)。

## 步骤一：碳纤维机身

- Base Color `(0.055, 0.065, 0.075)`；
- Metallic `0.32`，Roughness `0.38`；
- `Noise` Scale 110 → Bump，Strength 0.12 / Distance 0.006。

细密噪声能暗示碳纤维的编织感，不必真的建编织纹。

## 步骤二：枪金属与哑光聚合物

- **枪金属**：Base Color `(0.22, 0.25, 0.28)`，Metallic `0.82`，Roughness `0.32`；
- **哑光聚合物**：暗灰，Roughness `0.55`，用于传感器罩和面板缝。

> ⚠️ 高金属度会让漫反射颜色几乎消失。枪金属的 Base Color 要调亮一点，否则渲染出来一片死黑。

## 步骤三：发光材质

用 Principled 的 `Emission Color` / `Emission Strength`：

- 青色 LED：Color `(0.04, 0.62, 1.0)`，Strength `4.5`；
-  amber 天线尖：Color `(1.0, 0.45, 0.05)`，Strength `3.0`。

Base Color 给接近黑，让发光全靠 Emission 通道。

> ⚠️ 发光强度要配合合成器的 Bloom 阈值（05 章）。太低没辉光，太高会糊成一片白。

## 步骤四：材质分区清单

| 部件 | 材质 |
|------|------|
| 机身 / 机臂 | 碳纤维 |
| 上盖 / 电机 / 云台 | 枪金属 |
| 传感器罩 / 面板缝 | 哑光聚合物 |
| 桨叶 | 半光黑塑料 |
| 灯带 / 环形 LED | 青色发光 |
| 起落架 / 脚垫 | 金属 + 橡胶 |

## 本阶段自检

- 机身暗但有细节，不是死黑；
- 灯带在材质预览里已经明显发亮；
- 金属件和塑料件能区分开。
