# 01 · 参考分析：从顶视图看懂四轴

无人机的设计信息主要集中在**顶视图**。先看布局，再看细节。

打开 [阶段 1 快照](blends/01_reference.blend)，对照程序化生成的顶视参考图。

![顶视参考图](images/fig_reference.png)

## 步骤一：识别四大模块

1. **中央机身**：六边形舱体，承载传感器与飞控；
2. **四条机臂**：从中心对角辐射，末端各一个电机；
3. **四组旋翼**：每组两片桨叶，相邻电机转向相反（视觉上靠桨叶角度区分即可）；
4. **下方系统**：云台摄像头 + 起落架。

## 步骤二：定关键尺寸

| 项目 | 本案例数值 |
|------|-----------|
| 机身半径 | 0.62 |
| 机臂角度 | 45° / 135° / 225° / 315° |
| 电机轴距中心 | 1.72 |
| 桨叶长度 | 0.92 |
| 机身高度 | z = 1.55（悬停） |

## 步骤三：对称策略

四轴是**径向对称**，不是简单的镜像：

- 绕 Z 轴每 90° 重复一次；
- 每个电机、机臂、桨叶的形状完全一致，只是旋转角不同；
- 云台与起落架是前后/左右镜像，单独处理。

> ⚠️ 别手动复制四个机臂再逐个摆位置。用角度算坐标，后面改轴距只改一个数字。

## 本阶段自检

- 顶视图能数清四个电机；
- 轴距、臂角、机身半径已量化；
- 明确哪些部件走径向重复、哪些走镜像。
