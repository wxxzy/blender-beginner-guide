# 05 · 灯光渲染：夜景 + 辉光

打开 [阶段 5 快照](blends/05_lighting.blend)。

## 步骤一：夜景环境

- Background `(0.055, 0.065, 0.085)`，Strength `0.5`；
- 三盏面积光全用冷色：Key `(0.82, 0.90, 1.0)` / 520 W，Fill 冷蓝 / 200 W，Rim 冷白 / 460 W。

暗环境让发光条成为第二光源，这是科幻感的关键。

## 步骤二：相机

- 位置 `(5.0, -6.8, 4.8)`，看向 `(0, 0, 1.4)`，焦距 55 mm；
- 第一版相机太低，四轴 X 布局读不清；抬高到 4.8 后俯视角更明确。

> ⚠️ 对称模型最怕正面平视——会退化成一根横杆。俯视 30°~40° 才能读出结构。

## 步骤三：合成器 Bloom

Blender 5.2 的合成器是节点组，挂在 `scene.compositing_node_group`：

1. `CompositorNodeRLayers` → `CompositorNodeGlare`；
2. Glare Type 设 `Bloom`，Threshold `0.85`，Strength `0.5`，Size `0.55`；
3. Glare 输出 → `NodeGroupOutput` 的 Image 插口（需在 interface 里新建 socket）。

> ⚠️ 别忘在节点组 interface 里 `new_socket("Image", in_out="OUTPUT", socket_type="NodeSocketColor")`，否则合成器没有输出。

## 步骤四：渲染设置

EEVEE / 1400×1050 / 96 采样 / 屏幕光追 + 降噪 / AgX。

## 本阶段自检

- 灯带有柔和辉光，但没糊成一片；
- 机身在暗背景里仍有轮廓；
- 四轴布局一眼能数清。
