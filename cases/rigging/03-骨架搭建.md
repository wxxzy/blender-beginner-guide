# 03 · 骨架搭建：骨骼链与旋转模式

打开 [阶段 3 快照](blends/03_rigging.blend)。

## 骨骼链

```
Root (0,0,0.3 → 1.2)
└── Spine (1.2 → 1.5)
    └── Neck (1.5 → 1.9)
        └── Head (1.9 → 3.0)
            ├── Jaw
            ├── Eyelid.L
            └── Eyelid.R
```

## 关键坑：旋转模式

> ⚠️ **Pose Bone 默认 QUATERNION**。对 `rotation_euler` 加驱动器完全无效。必须设 `pose.bones["Jaw"].rotation_mode = 'XYZ'`。本案例首版三张表情图一模一样，就是这个原因。

## 自检

- 层级正确；需驱动的骨骼设为 XYZ；Jaw 摆动方向符合预期。
