# 04 · 蒙皮权重：手动分配

打开 [阶段 4 快照](blends/04_material.blend)。

## 顶点组与权重

头部按高度渐变：

```
z < 1.30        → Spine 100%
1.30 ~ 1.70     → Spine → Neck 渐变
1.70 ~ 2.05     → Neck → Head 渐变
下颌 + 正面     → Jaw 最高 85%
```

> ⚠️ 权重渐变比硬切换重要，1 直接跳 0 会产生折痕。

## Armature 修改器

Object 指骨架，勾 Use Vertex Groups。头部 Subdivision 放在 Armature **之后**——先形变再平滑。

> ⚠️ 曲线对象不支持顶点组，绑定前必须 `Object → Convert → Mesh`。脚本的 `bind_object()` 已处理。

## 自检

- 所有顶点至少被一组覆盖；转头时颈部无折痕；下颌随 Jaw 运动。
