# 04 · 材质贴图：工业配色逻辑

打开 [阶段 4 快照](blends/04_material.blend)。

## 步骤一：工业白机身

- Base Color `(0.72, 0.74, 0.75)`；
- Roughness `0.40`；
- Noise Bump 幅度很小（0.06），只做 sprayed paint 的细微颗粒。

> ⚠️ 白色外壳最容易过曝。Roughness 别低于 0.35，Key 灯别超过 600 W，否则高光糊成一片。

## 步骤二：关节深色件

`Base (0.07, 0.08, 0.09)` + Metallic 0.35。肩轴这类**正对相机的大金属面**尤其容易反射过曝，用深色材质比亮金属更稳。

## 步骤三：安全橙与橡胶

- 液压杆：橙 `(0.92, 0.38, 0.06)`，Roughness 0.46；
- 夹爪指垫：近黑橡胶，Roughness 0.88；
- 线缆：深色软质，Roughness 0.65。

橙色是工业设备的警示色，放在液压件上既合理又能打破白/灰的单调。

## 步骤四：状态灯

腕部小球用 Emission 青色 `(0.05, 0.70, 1.0)`，Strength 3.5。配合合成器轻微 Bloom 即可。

## 材质分区清单

| 部件 | 材质 |
|------|------|
| 转台 / 大臂 / 小臂 / 工具法兰 | 工业白 |
| 底座 / 关节销 / 肩轴 | 深色件 |
| 螺栓 / 腕壳 / 夹爪本体 | 拉丝钢 |
| 液压杆 | 安全橙 |
| 指垫 / 线缆 | 橡胶 / 软质黑 |
| 状态灯 | 青色发光 |

## 本阶段自检

- 白色外壳有细节，不是一片死白；
- 橙色液压杆清晰可辨；
- 深色关节与白臂形成明确对比。
