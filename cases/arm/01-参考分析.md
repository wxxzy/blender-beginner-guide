# 01 · 参考分析：侧视看关节链

机械臂的设计信息在**侧面**。先数关节，再看形状。

打开 [阶段 1 快照](blends/01_reference.blend)，对照侧视参考图。

![侧视参考图](images/fig_reference.png)

## 步骤一：数清六个轴

工业六轴机械臂从下到上依次是：

1. **J1 转台**：绕 Z 轴旋转（水平转动）；
2. **J2 肩**：绕 X 轴俯仰；
3. **J3 肘**：绕 X 轴俯仰；
4. **J4 腕滚转**：绕臂长轴旋转；
5. **J5 腕俯仰**：绕 X 轴；
6. **J6 工具滚转**：末端法兰旋转。

前三个轴决定末端位置，后三个轴决定末端姿态。

## 步骤二：定比例

| 部件 | 本案例尺寸 |
|------|-----------|
| 底座半径 | 0.62 |
| 转台高度 | 0.36 |
| 大臂长度 | 1.35 |
| 小臂长度 | 1.05 |
| 夹爪长度 | 0.34 |

## 步骤三：选一个展示姿态

机械臂默认姿态通常是直立的，渲染出来像一根柱子。给关节一点角度：

- 肩 `-38°`，肘 `+72°`，腕 `-34°`；
- 末端向前下方伸出，形成清晰的"Z"形剪影。

> ⚠️ 姿态要留出末端空间。夹爪顶到画面边缘会显得局促，取景时整体留白。

## 本阶段自检

- 能说出六个关节的旋转轴；
- 比例已量化；
- 姿态剪影清晰、不重叠。
