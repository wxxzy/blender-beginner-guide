# 05 · 常用快捷键速查

Blender 的键盘操作看似复杂，其实**高频的也就那么几十个**。下面按用途分类整理，建议打印或收藏。

## 视图与导航

| 快捷键 | 功能 |
|-------|------|
| 中键拖动 | 旋转视角 |
| Shift + 中键拖动 | 平移视角 |
| 滚轮 | 缩放视角 |
| 小键盘 `1/3/7` | 前/右/顶视图 |
| 小键盘 `0` | 摄像机视图 |
| 小键盘 `5` | 透视/正交切换 |
| 小键盘 `.` | 聚焦选中物体 |
| `Z` | 切换着色模式（线框/实体/渲染，弹出饼菜单） |

## 选择与对象操作

| 快捷键 | 功能 |
|-------|------|
| 左键 | 选择 |
| `A` / `Alt + A` | 全选 / 取消选择 |
| `Shift + 左键` | 加选或减选 |
| `B` / `C` | 框选 / 刷选 |
| `Shift + D` | 复制对象 |
| `Alt + D` | 关联复制（修改一个，全部同步变化） |
| `X` 或 `Delete` | 删除对象 |
| `Shift + A` | 添加新对象（弹出添加菜单） |
| `Tab` | 在物体模式与编辑模式之间切换 |
| `Ctrl + Z` / `Ctrl + Shift + Z` | 撤销 / 重做 |
| `Ctrl + J` | 合并多个对象为一个 |
| `Ctrl + S` | 保存文件 |
| `Ctrl + Shift + S` | 另存为 |

## 变换操作

| 快捷键 | 功能 |
|-------|------|
| `G` / `R` / `S` | 移动 / 旋转 / 缩放 |
| `X` / `Y` / `Z` | 约束到对应轴 |
| `Shift + 轴` | 约束到该轴以外的平面 |
| 输入数字 + 回车 | 精确设置数值 |
| 右键 / `Esc` | 取消当前操作 |
| `Alt + G/R/S` | 清除位置/旋转/缩放 |

## 编辑模式（建模常用）

> 先按 `Tab` 进入编辑模式，再用以下快捷键。

| 快捷键 | 功能 |
|-------|------|
| `1` / `2` / `3` | 顶点 / 边 / 面 选择模式 |
| `E` | 挤出（Extrude） |
| `Ctrl + R` | 环切（Loop Cut） |
| `Ctrl + B` | 倒角（Bevel） |
| `I` | 内插面（Inset） |
| `M` | 合并顶点（Merge） |
| `F` | 连接顶点 / 边成面 |
| `K` | 切割（Knife） |
| `Shift + 右键` | 移动 3D 光标 |
| `Shift + C` | 3D 光标归位，并重置视图 |

## 渲染与显示

| 快捷键 | 功能 |
|-------|------|
| `F12` | 渲染当前画面 |
| `Z` | 快速切换显示模式 |
| `N` | 打开/关闭右侧侧栏（含对象坐标等信息） |
| `T` | 打开/关闭左侧工具栏 |

> 💡 **不要死记硬背**。快捷键是在反复操作中自然记住的。刚开始可以边看这份表边操作，一周后你会发现大部分已经形成肌肉记忆。
