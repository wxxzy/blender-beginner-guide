# 02 · 认识 Blender

## 一句话认识 Blender

Blender 是一款**免费、开源、功能完整的三维创作软件**。你可以把它理解成一个"三维世界里的万能工具箱"——建模、上色、打光、渲染、动画、特效、剪辑，甚至做游戏素材，它几乎都能做。很多专业工作室（包括制作动画短片、游戏资产的团队）都在用它。

## 它能帮你做出什么

| 方向 | 能做什么 | 举例 |
|------|---------|------|
| 建模 | 搭建三维物体的形状 | 一个杯子、一把椅子、一个卡通角色 |
| 材质 | 给物体表面定义颜色与质感 | 金属、木头、玻璃、皮肤 |
| 灯光 | 布置场景光照 | 柔和的日光、戏剧性的聚光灯 |
| 渲染 | 把三维场景"拍"成二维图片 | 产品效果图、插画 |
| 动画 | 让物体动起来 | 角色行走、机械运动 |
| 视频 | 剪辑与合成 | 短片后期 |

## 先建立两个核心概念

在动手之前，先理解两个词，后面会反复用到：

- **视图（Viewport）**：你看到的那个"三维空间窗口"。它不是最终的图，只是你在"观察和摆弄"模型的工作台。**在视图里看到的样子 ≠ 渲染出来的样子**，这一点新手极易混淆。
- **对象（Object）**：三维场景里的每一个独立个体都叫"对象"，比如一个立方体、一盏灯、一台摄像机。你选中、移动、删除的，本质上都是"对象"。

> 记住这两点，你就已经跨过了三维软件的第一道门槛。
