# 09 · 常见新手误区

这一章可能是整份指南**最值钱**的部分——那些别人踩过、帮你省下大量时间的坑。

## 误区一：想一次学会所有功能

**症状**：刚学三天，又去研究雕刻、又去学动画、又想做粒子特效，最后什么都没学成。
**正解**：**先专注"建模 + 材质 + 渲染"这条主线**。把这条线跑通、做出几个完整作品后，再按兴趣扩展到其他模块。Blender 大而全，但初学者只需要很小的一部分。

## 误区二：迷信快捷键，死记硬背

**症状**：抄了一张快捷键表，背得头昏脑涨，真操作时还是想不起来。
**正解**：快捷键是**用出来的，不是背出来的**。先记住最核心的十来个（G/R/S、Tab、Shift+A、中键导航），其余的在做作品时自然就会了。

## 误区三：混淆"物体模式"和"编辑模式"

**症状**：想捏形状却发现只能整体移动；或者想移动整个物体却把某个点拖飞了。
**正解**：记住 **`Tab` 切换模式**。做整体操作 → 物体模式；捏点线面 → 编辑模式。迷路时先看左上角显示的是什么模式。

## 误区四：以为视图里看到的就是最终效果

**症状**：在视图里看着挺好，一渲染发现完全不是那么回事。
**正解**：视图区有**多种显示模式**（线框 / 实体 / 材质预览 / 渲染）。默认可能是"实体"模式，只看得到形状看不到材质。按 `Z` 切换到 **Rendered（渲染）** 模式，才能看到接近最终效果的样子。

## 误区五：建模时不注意面数，模型越建越卡

**症状**：模型动辄几十万面，软件卡到不动。
**正解**：**面数够用就好**。细分曲面、环切等操作都会增加面数，视口级别别盲目调高。先把形状做对，面数优化留到后面。

## 误区六：从不保存，或把 .blend 当成图片

**症状**：辛苦做了两小时，软件崩溃，白干；或者以为保存 `.blend` 就等于导出了图片。
**正解**：
- **养成随手 `Ctrl + S` 的习惯**（Blender 有自动保存，但别全指望它）；
- 分清 **`.blend`（工程文件）** 和 **导出的图片（PNG / JPG）**——这是两码事。

## 误区七：一上来就想做复杂角色 / 写实场景

**症状**：第一个作品就想做个逼真的人脸，结果处处受挫，信心崩了。
**正解**：**从简单几何体开始**。杯子、桌子、简单的卡通形象，都比"写实人脸"更适合练手。能力是一层层叠上去的。

## 误区八：只用触控板，或没有三键鼠标

**症状**：用触控板操作，视角控制极其别扭，操作效率低。
**正解**：**配一个带中键滚轮的鼠标**。这是性价比最高的"硬件投资"，能显著改善学习体验。
