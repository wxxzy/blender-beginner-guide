# Blender 高级功能教程

> 这份教程讲的是 Blender 里那些"用过但没搞懂"的功能：雕刻、物理、绑定、UV 烘焙、体积光、扩展开发。
> 每一章的代码都在 Blender 5.2 上真实跑过，配图是脚本生成的渲染结果。

---

## 这份教程和前面两版是什么关系

仓库里现在有三条线，能力要求逐级上升：

```
basic/      入门：认识界面、会做一个小模型、会按 F12
advanced/   进阶：用 Python 程序化生成整个场景（bmesh / 修改器 / 材质节点 / 合成器 / 运镜）
pro/        高级：Blender 的专业功能模块（本教程）
```

**advanced 教你"用代码批量造东西"，pro 教你"专业功能怎么用"**。两者不重叠：

| | advanced | pro |
|---|---|---|
| 雕刻 | 只提了 remesh 修改器 | 重拓扑、动态拓扑、细节位移的完整流程 |
| 物理 | 没涉及 | 刚体、布料、MPM 流体、毛发，含求解与缓存 |
| 角色 | 没涉及 | 骨骼链、自动权重、IK、形变控制 |
| 贴图 | 只讲程序化 | UV 展开、Smart Project、烘焙成位图 |
| 渲染 | 讲合成器链路 | 体积散射、色彩管理、渲染通道、探针 |
| 扩展 | 没涉及 | 资产库、Python 插件（Operator / Panel / 注册） |

## 需要的底子

- 装好 Blender 4.2 或更高（本教程在 **5.2.2 LTS** 实测）
- 会写最基础的 Python：`import`、函数、循环、`for`
- 知道 `bpy.data.objects` / `bpy.context` 是什么（不知道的话先看 advanced 的 00 篇）

不需要美术基础。所有内容都是"可复现的技术"，不是靠手感。

## 每章的结构

统一四段，方便你跳读：

1. **它解决什么问题** —— 什么时候该用它
2. **核心概念** —— 三到五个关键术语，讲透
3. **可运行代码** —— 整段复制到 Blender 文本编辑器就能跑
4. **实测踩坑** —— 我真实撞到的报错和正确写法

第 4 段是这份教程最值钱的部分。Blender 的 API 在 4.x → 5.x 之间改了不少名字，
网上大量教程还在用旧写法，照抄就报 `AttributeError`。这里记的都是 5.2 上的真实结果。

## 一个必须提前知道的事

**后台模式（`blender -b`）不会自动推进物理与仿真。**

```python
scene.frame_set(90)          # ❌ 不会模拟，物体停在初始位置
for f in range(1, 91):       # ✅ 必须逐帧推进
    scene.frame_set(f)
```

这是第 02 章的第一个坑，也是所有物理类功能的共同前提。先用一次记住，后面能省两小时。

## 配套脚本

`scripts/` 下有 5 个验证脚本，对应五组功能的实测：

```bash
blender -b --factory-startup -noaudio -P scripts/verify_pro_a.py -- ./out
```

| 脚本 | 覆盖 | 关键输出 |
|---|---|---|
| `verify_pro_a.py` | 雕刻、绑定、UV、资产、插件 | `sculpt_verts=94170` / `RIG auto=True` |
| `verify_pro_b.py` | 刚体、布料 | `SIMULATED frames=1..90` |
| `verify_pro_c.py` | 流体、毛发 | `FLUID liquid_mesh_verts=70742` |
| `verify_pro_d.py` | 体积光、色彩管理 | `RAYTRACING_ON` |
| `verify_pro_e.py` | 烘焙、仿真区结构 | `BAKE saved=True` |

跑一遍大约 5 分钟（不含流体，流体单独约 1 分钟）。

## 版本提示

本教程的代码按 **Blender 5.2** 编写。4.2 及以上大多可直接跑，差异会标在各章的"踩坑"里。
主要变化集中在：合成器改成节点组、`Action.fcurves` 移除、EEVEE 更名与透明材质属性重做。
